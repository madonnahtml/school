Parte 2 – Operatori di confronto

Gli operatori da utilizzare sono: ==, !=, >, <, >=, <=.

Ripasso lampoUn confronto mette a paragone due valori e dà come risultato true (vero) o false (falso). Attenzione: == (due uguali) confronta, = (uno solo) assegna.
01Confronti facile

Consegna. Scrivi un programma che dichiari:

int a = 15;
int b = 10;

e visualizzi il risultato dei seguenti confronti:

  • a == b
  • a != b
  • a > b
  • a < b
  • a >= b
  • a <= b

Domanda: che tipo di valore restituisce ogni confronto?

Risposta spiegata

Ragionamento

  1. Un confronto si può stampare direttamente: Java lo calcola e scrive true o false.
  2. Il confronto va messo tra parentesi dentro la concatenazione: "a == b -> " + (a == b). Senza parentesi Java proverebbe prima a fare "testo" + a e poi a confrontare una stringa con un numero, e non compila.

Codice

public class Confronti {
    public static void main(String[] args) {
        int a = 15;
        int b = 10;

        System.out.println("a == b -> " + (a == b));
        System.out.println("a != b -> " + (a != b));
        System.out.println("a > b  -> " + (a > b));
        System.out.println("a < b  -> " + (a < b));
        System.out.println("a >= b -> " + (a >= b));
        System.out.println("a <= b -> " + (a <= b));
    }
}

Output

a == b -> false
a != b -> true
a > b  -> true
a < b  -> false
a >= b -> true
a <= b -> false

Risposta alla domanda

Ogni confronto restituisce un valore di tipo boolean, cioè true oppure false. Per questo si può anche salvare in una variabile: boolean uguali = (a == b);. Ed è proprio questo valore che if, while e for usano per decidere cosa fare.

Parte 3 – if, else e else if

Ripasso lampoJava controlla le condizioni dall'alto verso il basso ed esegue solo il primo ramo la cui condizione è vera; l'else finale scatta se nessuna lo è.
02Maggiore, minore o uguale facile

Consegna. Chiedi all'utente due numeri interi.

Il programma deve stabilire se:

  • il primo è maggiore del secondo;
  • il primo è minore del secondo;
  • i due numeri sono uguali.

Utilizza: if, else if, else.

Risposta spiegata

Ragionamento

  1. Leggo i due numeri con Scanner e nextInt().
  2. I casi sono tre e si escludono a vicenda: con if controllo "maggiore", con else if "minore".
  3. Se non è né maggiore né minore, l'unica possibilità rimasta è che siano uguali: basta l'else, senza scrivere primo == secondo.

Codice

import java.util.Scanner;

public class MaggioreMinoreUguale {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);

        System.out.print("Primo numero: ");
        int primo = in.nextInt();
        System.out.print("Secondo numero: ");
        int secondo = in.nextInt();

        if (primo > secondo) {
            System.out.println("Il primo è maggiore del secondo");
        } else if (primo < secondo) {
            System.out.println("Il primo è minore del secondo");
        } else {
            System.out.println("I due numeri sono uguali");
        }
        in.close();
    }
}

Output (tre esecuzioni)

Primo numero: 12
Secondo numero: 7
Il primo è maggiore del secondo

Primo numero: 3
Secondo numero: 9
Il primo è minore del secondo

Primo numero: 5
Secondo numero: 5
I due numeri sono uguali

Perché funziona

Per provare un programma con if bisogna eseguirlo una volta per ogni ramo: qui tre esecuzioni, una per caso. Se provi solo con 12 e 7 non sai se gli altri due rami sono giusti.

03Controllo del voto facile

Consegna. Chiedi all'utente un voto compreso tra 0 e 10.

Visualizza:

  • Eccellente → 9-10
  • Buono → 8
  • Sufficiente → 6-7
  • Insufficiente → 0-5

Utilizza if / else if / else.

Attenzione: l'ordine delle condizioni è importante.

Risposta spiegata

Ragionamento

  1. Parto dalla fascia più alta: voto >= 9. Se è falsa so già che il voto è al massimo 8.
  2. Quindi nel ramo successivo basta voto >= 8 (che a quel punto significa "esattamente 8"), poi voto >= 6 (cioè 6 o 7).
  3. Tutto il resto (0-5) va nell'else.
  4. In più, come prima condizione, scarto i voti fuori dall'intervallo 0-10 con ||: un 12 altrimenti diventerebbe "Eccellente".

Codice

import java.util.Scanner;

public class ControlloVoto {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);

        System.out.print("Voto (0-10): ");
        int voto = in.nextInt();

        // prima scarto i valori fuori intervallo, poi controllo dal voto più alto
        if (voto < 0 || voto > 10) {
            System.out.println("Voto non valido");
        } else if (voto >= 9) {
            System.out.println("Eccellente");
        } else if (voto >= 8) {
            System.out.println("Buono");
        } else if (voto >= 6) {
            System.out.println("Sufficiente");
        } else {
            System.out.println("Insufficiente");
        }
        in.close();
    }
}

Output (cinque esecuzioni)

Voto (0-10): 10
Eccellente

Voto (0-10): 8
Buono

Voto (0-10): 7
Sufficiente

Voto (0-10): 4
Insufficiente

Voto (0-10): 12
Voto non valido

Perché l'ordine è importante

Se scrivessi per prima voto >= 6, un 9 la renderebbe vera e stamperebbe "Sufficiente": Java non guarderebbe più i rami sotto. Con gli else if si va dalla condizione più restrittiva alla più larga. È esattamente l'errore dell'esercizio 31.

04Accesso facile

Consegna. Dichiara:

int eta;
boolean badge;

Chiedi all'utente età e possesso del badge.

L'accesso è consentito solo se:

  • l'utente ha almeno 18 anni;
  • possiede il badge.

Utilizza &&.

Esempio:

Età: 20
Badge valido? true

Accesso consentito
Risposta spiegata

Ragionamento

  1. Per leggere un boolean c'è nextBoolean(): l'utente scrive true o false.
  2. Le due richieste devono valere insieme: eta >= 18 && badge.
  3. badge è già un boolean: scrivere badge == true funzionerebbe, ma è inutile.

Codice

import java.util.Scanner;

public class Accesso {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int eta;
        boolean badge;

        System.out.print("Età: ");
        eta = in.nextInt();
        System.out.print("Badge valido? ");
        badge = in.nextBoolean();   // l'utente scrive true oppure false

        if (eta >= 18 && badge) {
            System.out.println("Accesso consentito");
        } else {
            System.out.println("Accesso negato");
        }
        in.close();
    }
}

Output (due esecuzioni)

Età: 20
Badge valido? true
Accesso consentito

Età: 16
Badge valido? true
Accesso negato

Errori da evitare

  • Scrivere 18 <= eta <= 99 come in matematica: in Java non compila, va spezzato in eta >= 18 && eta <= 99.
  • Se l'utente scrive si invece di true, nextBoolean() si ferma con un errore (InputMismatchException): il PDF chiede proprio true/false.

Il programma deve visualizzare Weekend se il numero è 6 oppure 7.

Utilizza ||.

06Negazione facile

Consegna. Dichiara:

boolean piove;

Se non piove, stampa:

Possiamo uscire

Utilizza l'operatore !.

Risposta spiegata

Ragionamento

  1. Do a piove un valore: false (non piove). Una variabile locale va inizializzata prima di essere letta, altrimenti il compilatore dà errore.
  2. !piove vale true quando piove è false: è proprio "se non piove".

Codice

public class Negazione {
    public static void main(String[] args) {
        boolean piove = false;

        if (!piove) {          // si legge: "se NON piove"
            System.out.println("Possiamo uscire");
        }
    }
}

Output

Possiamo uscire

Perché funziona

Se cambi la prima riga in boolean piove = true; il programma non stampa niente: !true è false e il blocco dell'if viene saltato. if (!piove) si legge meglio di if (piove == false), anche se fanno la stessa cosa.

Parte 5 – if annidati

07Accesso con controllo doppio medio

Consegna. Realizza un programma che chieda:

Età:
Possiedi il badge? true/false

Il programma deve comportarsi così:

  1. se l'età è inferiore a 18 → Accesso vietato;
  2. se l'età è almeno 18:
    • se il badge è valido → Accesso consentito;
    • altrimenti → Badge non valido.

Utilizza un if annidato.

Risposta spiegata

Ragionamento

  1. Il primo controllo è sull'età. Se è minore di 18 il badge non interessa nemmeno.
  2. Nell'else (età almeno 18) metto un secondo if, dentro il primo, che guarda il badge. La seconda domanda dipende dalla risposta alla prima: è questo il caso dell'if annidato.

Codice

import java.util.Scanner;

public class AccessoDoppio {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);

        System.out.print("Età: ");
        int eta = in.nextInt();
        System.out.print("Possiedi il badge? true/false ");
        boolean badge = in.nextBoolean();

        if (eta < 18) {
            System.out.println("Accesso vietato");
        } else {
            // qui dentro so già che eta >= 18
            if (badge) {
                System.out.println("Accesso consentito");
            } else {
                System.out.println("Badge non valido");
            }
        }
        in.close();
    }
}

Output (tre esecuzioni, una per ramo)

Età: 15
Possiedi il badge? true/false true
Accesso vietato

Età: 20
Possiedi il badge? true/false true
Accesso consentito

Età: 20
Possiedi il badge? true/false false
Badge non valido

Differenza con l'esercizio 4

Con && c'erano solo due esiti (consentito / negato). Con l'if annidato ce ne sono tre, e il messaggio dice perché l'accesso non va: troppo giovane oppure badge mancante. Nota che il programma chiede il badge anche al quindicenne: per non chiederlo si potrebbe spostare la seconda domanda dentro l'else.

Parte 6 – Operatore ternario

Ripasso lampocondizione ? valoreSeVera : valoreSeFalsa è un if...else compatto che produce un valore, da assegnare a una variabile o stampare.
08Numero maggiore facile

Consegna. Chiedi due numeri interi e trova il maggiore utilizzando esclusivamente il ternario.

Struttura attesa:

int maggiore = ... ? ... : ...;

Visualizza il risultato.

Risposta spiegata

Ragionamento

  1. La condizione è a > b; se è vera il maggiore è a, altrimenti b.
  2. Riempio lo schema: int maggiore = a > b ? a : b;

Codice

import java.util.Scanner;

public class NumeroMaggiore {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);

        System.out.print("Primo numero: ");
        int a = in.nextInt();
        System.out.print("Secondo numero: ");
        int b = in.nextInt();

        int maggiore = a > b ? a : b;   // condizione ? valore se vera : valore se falsa

        System.out.println("Il maggiore è " + maggiore);
        in.close();
    }
}

Output

Primo numero: 8
Secondo numero: 13
Il maggiore è 13

Perché funziona

Se i numeri sono uguali, a > b è falso e viene scelto b: va bene lo stesso, perché è uguale ad a. I due valori dopo ? e : devono essere dello stesso tipo della variabile (qui int).

Parte 7 – switch

10Giorno della settimana facile

Consegna. Chiedi un numero da 1 a 7.

Utilizza switch per visualizzare:

1 → Lunedì
2 → Martedì
3 → Mercoledì
4 → Giovedì
5 → Venerdì
6 → Sabato
7 → Domenica

Per ogni case utilizza break.

Se il numero non è valido, visualizza Valore non valido utilizzando default.

Risposta spiegata

Ragionamento

  1. switch (n) confronta n con i valori dei case e salta a quello uguale.
  2. Ogni case finisce con break, che fa uscire dallo switch.
  3. default raccoglie tutti gli altri valori (0, 8, -3…). Essendo l'ultimo non ha bisogno di break.

Codice

import java.util.Scanner;

public class GiornoSettimana {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);

        System.out.print("Numero (1-7): ");
        int n = in.nextInt();

        switch (n) {
            case 1:
                System.out.println("Lunedì");
                break;
            case 2:
                System.out.println("Martedì");
                break;
            case 3:
                System.out.println("Mercoledì");
                break;
            case 4:
                System.out.println("Giovedì");
                break;
            case 5:
                System.out.println("Venerdì");
                break;
            case 6:
                System.out.println("Sabato");
                break;
            case 7:
                System.out.println("Domenica");
                break;
            default:
                System.out.println("Valore non valido");
        }
        in.close();
    }
}

Output (due esecuzioni)

Numero (1-7): 3
Mercoledì

Numero (1-7): 9
Valore non valido

Perché serve il break

Senza break, dopo il case giusto Java continua a eseguire anche i case successivi (si chiama fall-through): con 3 stamperebbe da Mercoledì fino a "Valore non valido". Lo vedi provato nella domanda 13 della Parte 18.

Parte 8 – Classe Math

Utilizza i metodi presenti nella classe Math.

Ripasso lampoMath non si importa e non si crea: si scrive Math. seguito dal metodo. abs, min, max restituiscono lo stesso tipo che ricevono; pow e sqrt restituiscono sempre un double; Math.PI è una costante (senza parentesi).
11Valore assoluto facile

Consegna. Chiedi due numeri e calcola la loro distanza utilizzando Math.abs().

Esempio:

Primo numero: 10
Secondo numero: 25

Distanza: 15
Risposta spiegata

Ragionamento

  1. La distanza è la differenza, ma senza segno: 10 - 25 = -15, e una distanza negativa non ha senso.
  2. Math.abs toglie il segno: Math.abs(-15) vale 15. Così l'ordine in cui l'utente scrive i numeri non conta più.

Codice

import java.util.Scanner;

public class ValoreAssoluto {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);

        System.out.print("Primo numero: ");
        int a = in.nextInt();
        System.out.print("Secondo numero: ");
        int b = in.nextInt();

        int distanza = Math.abs(a - b);   // il segno non conta: 10-25 e 25-10 danno 15

        System.out.println("Distanza: " + distanza);
        in.close();
    }
}

Output (due esecuzioni)

Primo numero: 10
Secondo numero: 25
Distanza: 15

Primo numero: 25
Secondo numero: 10
Distanza: 15
12Minimo e massimo facile

Consegna. Chiedi due numeri.

Utilizza Math.min() e Math.max() per visualizzare:

Numero minore: ...
Numero maggiore: ...
Risposta spiegata

Ragionamento

Math.min(a, b) restituisce il più piccolo dei due, Math.max(a, b) il più grande. Posso metterli direttamente nella stampa, senza variabili d'appoggio.

import java.util.Scanner;

public class MinimoMassimo {

        int b = in.nextInt();

        System.out.println("Numero minore: " + Math.min(a, b));

Primo numero: 14
Secondo numero: -3
Numero minore: -3
Numero maggiore: 14

Perché funziona

È la versione "pronta" del ternario dell'esercizio 8: Math.max(a, b) fa la stessa cosa di a > b ? a : b. Ricevono due valori alla volta: per tre numeri si annidano, Math.max(a, Math.max(b, c)).

13Potenza e radice facile

Consegna. Chiedi un numero n.

Calcola:

  1. n² utilizzando Math.pow();
  2. la radice quadrata di n utilizzando Math.sqrt().

Ricorda che questi metodi restituiscono un double.

Risposta spiegata

Ragionamento

  1. Math.pow(base, esponente): per il quadrato Math.pow(n, 2).
  2. Math.sqrt(n) calcola la radice quadrata.
  3. Entrambi restituiscono double, quindi i risultati vanno in variabili double: scrivere int q = Math.pow(n, 2); non compila (da double a int si perderebbe precisione).

Codice

import java.util.Scanner;

public class PotenzaRadice {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);

        System.out.print("n: ");
        int n = in.nextInt();

        double quadrato = Math.pow(n, 2);   // n elevato alla 2
        double radice = Math.sqrt(n);

        System.out.println("n al quadrato: " + quadrato);
        System.out.println("Radice quadrata di n: " + radice);
        in.close();
    }
}

Output (due esecuzioni)

n: 9
n al quadrato: 81.0
Radice quadrata di n: 3.0

n: 2
n al quadrato: 4.0
Radice quadrata di n: 1.4142135623730951

Da notare

Vedi 81.0 e non 81: è la prova che il risultato è un double. Con un numero negativo Math.sqrt non dà errore ma restituisce NaN ("Not a Number").

14Cerchio facile

Consegna. Chiedi all'utente il raggio di un cerchio.

Calcola:

Circonferenza = 2 × π × r
Area = π × r²

Utilizza: Math.PI, Math.pow().

Visualizza entrambi i risultati.

Risposta spiegata

Ragionamento

  1. Il raggio può avere la virgola: lo leggo come double con nextDouble().
  2. Traduco le formule: 2 * Math.PI * r e Math.PI * Math.pow(r, 2). In Java il "per" è sempre *, non si può sottintendere.
  3. Stampo i valori completi e, per leggibilità, anche arrotondati a 2 decimali con printf e %.2f.

Codice

import java.util.Scanner;

public class Cerchio {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);

        System.out.print("Raggio: ");
        double r = in.nextDouble();

        double circonferenza = 2 * Math.PI * r;
        double area = Math.PI * Math.pow(r, 2);

        System.out.println("Circonferenza: " + circonferenza);
        System.out.println("Area: " + area);
        System.out.printf("Arrotondati: circonferenza %.2f, area %.2f%n", circonferenza, area);
        in.close();
    }
}

Output

Raggio: 3
Circonferenza: 18.84955592153876
Area: 28.274333882308138
Arrotondati: circonferenza 18.85, area 28.27
Virgola o punto?Su un computer impostato in italiano Scanner vuole i decimali con la virgola (2,5; scrivere 2.5 dà InputMismatchException) e printf stampa 18,85. L'output qui sopra viene da un computer in inglese, per questo c'è il punto. La stampa con + ("Area: " + area) usa invece sempre il punto.

20Validazione medio

Consegna. Chiedi all'utente un numero compreso tra 1 e 100.

Valore non valido.

Ragionamento

  1. La domanda va fatta almeno una volta: è il caso tipico del do-while.

import java.util.Scanner;

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n;

        do {
            System.out.print("Inserisci un numero tra 1 e 100: ");
            n = in.nextInt();
            if (n < 1 || n > 100) {
                System.out.println("Valore non valido.");
            }
        } while (n < 1 || n > 100);    // ripeto finché il valore è fuori intervallo

        System.out.println("Numero valido!");
        in.close();
    }
}

Scrivere n < 1 && n > 100: un numero non può essere insieme minore di 1 e maggiore di 100, quindi la condizione è sempre falsa e il programma accetterebbe anche 150. Per "fuori dall'intervallo" si usa ||; per "dentro" si usa && (n >= 1 && n <= 100).

28Analisi di numeri difficile

Consegna. Realizza un programma che chieda numeri all'utente fino all'inserimento di 0.

Il programma deve calcolare:

  • quantità di numeri inseriti;
  • somma;
  • media;
  • valore massimo;
  • valore minimo;
  • quantità di numeri pari;
  • quantità di numeri dispari.

Requisiti. Devi utilizzare:

  • Scanner;
  • while;
  • if;
  • else;
  • operatori di confronto;
  • operatore %;
  • almeno un operatore logico dove appropriato.

Attenzione. Lo 0 serve per terminare l'inserimento e non deve essere considerato tra i numeri analizzati.

Output finale di esempio

Numeri inseriti: 5
Somma: 37
Media: 7.4
Massimo: 15
Minimo: 2
Numeri pari: 2
Numeri dispari: 3
Risposta spiegata

Ragionamento

  1. Struttura. È l'esercizio 19 (lettura anticipata + while (n != 0)) con più contatori. Così lo 0 non entra mai nel ciclo e non viene analizzato.
  2. Variabili. Prima del ciclo: quanti, somma, pari, dispari a 0, più massimo e minimo.
  3. Massimo e minimo. Non posso partire da 0: se l'utente inserisce solo numeri negativi il massimo resterebbe 0, che non è stato inserito. Il trucco: il primo numero diventa sia massimo sia minimo. Lo scrivo con l'operatore logico: if (quanti == 1 || n > massimo). Al primo giro la parte sinistra è vera e Java non guarda nemmeno la destra.
  4. Pari e dispari. n % 2 == 0 → pari, altrimenti (else) dispari. L'else è importante con i negativi: -9 % 2 vale -1, non 1, quindi il test n % 2 == 1 sbaglierebbe.
  5. Media. somma / quanti tra due int darebbe un intero (37 / 5 = 7). Con il cast (double) somma / quanti si ottiene 7.4.
  6. Nessun numero. Se il primo numero è 0, quanti è 0 e la media sarebbe una divisione per zero: lo controllo con un if prima di stampare.

Codice

import java.util.Scanner;

public class AnalisiNumeri {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int quanti = 0;
        int somma = 0;
        int massimo = 0;
        int minimo = 0;
        int pari = 0;
        int dispari = 0;

        System.out.print("Numero (0 per finire): ");
        int n = in.nextInt();

        while (n != 0) {                 // lo 0 non entra mai nel ciclo
            quanti++;
            somma += n;

            // il primo numero è sia massimo sia minimo; poi confronto
            if (quanti == 1 || n > massimo) {
                massimo = n;
            }
            if (quanti == 1 || n < minimo) {
                minimo = n;
            }

            if (n % 2 == 0) {
                pari++;
            } else {
                dispari++;
            }

            System.out.print("Numero (0 per finire): ");
            n = in.nextInt();
        }

        if (quanti > 0) {
            double media = (double) somma / quanti;
            System.out.println("Numeri inseriti: " + quanti);
            System.out.println("Somma: " + somma);
            System.out.println("Media: " + media);
            System.out.println("Massimo: " + massimo);

Risposta spiegata

Passo 1 · Lo scheletro: il menu dell'esercizio 21

Un do-while che stampa il menu, legge scelta e la passa a uno switch, finché scelta != 0. Ogni opzione è un case; le scelte inesistenti finiscono nel default.

Passo 2 · L'array predisposto

Prima del ciclo creo int[] numeri = new int[50]; e un contatore quanti che dice quante celle sono occupate. Devono stare fuori dal do-while: l'opzione 3 li riempie, l'opzione 4 li legge in un giro successivo del menu. Un array nuovo di int ha tutte le celle a 0, e 0 non può mai essere un numero inserito (è il terminatore): quindi la prima cella a 0 segna la fine dei dati.

Passo 3 · Opzione 1 e 2

  • Area: Math.PI * Math.pow(r, 2), con un if / else che rifiuta i raggi negativi.
  • Confronto: se a == b sono uguali, altrimenti il maggiore è Math.max(a, b).

Passo 4 · Opzione 3: inserire e attraversare

  1. Un do-while legge numeri fino allo 0. Memorizzo il numero solo se n != 0 && quanti < numeri.length: non è il terminatore e c'è ancora posto. Se l'array è pieno lo segnalo (else if) invece di andare oltre l'ultima cella, che darebbe ArrayIndexOutOfBoundsException.
  2. Se si sceglie di nuovo l'opzione 3, i nuovi numeri si aggiungono dopo quelli già presenti (riparto da quanti).
  3. Poi un foreach attraversa l'array e stampa i numeri; alla prima cella a 0 esce con break, perché da lì in poi le celle sono vuote.

Passo 5 · Opzione 4: statistiche con for e Math

Se quanti == 0 non c'è niente da calcolare. Altrimenti un for classico da 0 a quanti - 1 (solo le celle occupate) calcola somma, pari, dispari e aggiorna massimo = Math.max(massimo, numeri[i]) e minimo = Math.min(minimo, numeri[i]), partendo dal primo elemento. La media usa il cast a double.

Codice completo

import java.util.Scanner;

public class MiniProgramma {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int[] numeri = new int[50];   // array predisposto: le celle libere valgono 0
        int quanti = 0;               // quante celle sono occupate
        int scelta;
        int n;

        do {
            System.out.println("===== MENU =====");
            System.out.println("1. Calcola area cerchio");
            System.out.println("2. Confronta due numeri");
            System.out.println("3. Inserisci numeri");
            System.out.println("4. Visualizza statistiche");
            System.out.println("0. Esci");
            System.out.print("Scelta: ");
            scelta = in.nextInt();

            switch (scelta) {
                case 1:
                    System.out.print("Raggio: ");
                    double r = in.nextDouble();
                    if (r < 0) {
                        System.out.println("Il raggio non può essere negativo.");
                    } else {
                        double area = Math.PI * Math.pow(r, 2);
                        System.out.printf("Area: %.2f%n", area);
                    }
                    break;

                case 2:
                    System.out.print("Primo numero: ");
                    int a = in.nextInt();
                    System.out.print("Secondo numero: ");
                    int b = in.nextInt();
                    if (a == b) {
                        System.out.println("I due numeri sono uguali.");
                    } else {
                        System.out.println("Il maggiore è " + Math.max(a, b));
                    }
                    break;

                case 3:
                    do {
                        System.out.print("Numero (0 per terminare): ");
                        n = in.nextInt();
                        if (n != 0 && quanti < numeri.length) {
                            numeri[quanti] = n;
                            quanti++;
                        } else if (n != 0) {
                            System.out.println("Array pieno: numero non memorizzato.");
                        }
                    } while (n != 0);

                    // foreach: scorro l'array; la prima cella a 0 è libera, quindi mi fermo
                    System.out.print("Numeri memorizzati:");
                    for (int x : numeri) {
                        if (x == 0) {
                            break;
                        }
                        System.out.print(" " + x);
                    }
                    System.out.println();
                    break;

                case 4:
                    if (quanti == 0) {
                        System.out.println("Nessun numero inserito: usa prima l'opzione 3.");
                    } else {
                        int somma = 0;
                        int massimo = numeri[0];
                        int minimo = numeri[0];
                        int pari = 0;
                        int dispari = 0;
                        for (int i = 0; i < quanti; i++) {   // solo le celle occupate
                            somma += numeri[i];
                            massimo = Math.max(massimo, numeri[i]);
                            minimo = Math.min(minimo, numeri[i]);
                            if (numeri[i] % 2 == 0) {
                                pari++;
                            } else {
                                dispari++;
                            }
                        }
                        double media = (double) somma / quanti;
                        System.out.println("Somma: " + somma);
                        System.out.printf("Media: %.2f%n", media);
                        System.out.println("Massimo: " + massimo);
                        System.out.println("Minimo: " + minimo);
                        System.out.println("Numeri pari: " + pari);
                        System.out.println("Numeri dispari: " + dispari);
                    }
                    break;

                case 0:
                    System.out.println("Programma terminato.");
                    break;

                default:
                    System.out.println("Scelta non valida.");
            }
            System.out.println();
        } while (scelta != 0);

        in.close();
    }
}

Cosa succede

Sufficiente

Con voto = 9 il programma stampa "Sufficiente" invece di "Eccellente".

Perché

In una catena if / else if viene eseguito solo il primo ramo vero, e poi gli altri vengono saltati. Ogni voto da 8 in su è anche >= 6, quindi si ferma sempre al primo ramo: i rami "Buono" ed "Eccellente" si raggiungono solo se il voto è minore di 6, ma in quel caso le loro condizioni (>= 8, >= 9) sono false. Non vengono mai eseguiti. Il compilatore non segnala niente: è un errore di logica.

        int[] prove = {9, 8, 6, 4};

        for (int voto : prove) {
            System.out.print(voto + " -> ");
            if (voto >= 9) {                 // dalla condizione più restrittiva...
                System.out.println("Eccellente");
            } else if (voto >= 8) {
                System.out.println("Buono");
            } else if (voto >= 6) {          // ...alla più larga
                System.out.println("Sufficiente");
            } else {
                System.out.println("Insufficiente");
            }
        }

}

Risposte spiegate
  1. while controlla la condizione prima, do-while dopo. Quindi il while può non eseguire mai il blocco (condizione falsa subito), il do-while lo esegue almeno una volta. Per questo il do-while è perfetto per menu e validazione dell'input (esercizi 20 e 21).
  2. Quando il numero di iterazioni è noto prima di iniziare: contare da 1 a 20, leggere 5 numeri, scorrere un array con l'indice. Inizializzazione, condizione e aggiornamento stanno nella stessa riga, quindi è difficile dimenticare l'aggiornamento.
  3. Per attraversare tutti gli elementi di un array (o di una collezione), dal primo all'ultimo, quando serve il valore ma non la posizione: for (int n : numeri). Non va bene se ti serve l'indice o se devi modificare le celle.
  4. break esce dal ciclo, continue salta solo il giro corrente. Con break a i == 5 l'output è 1-4; con continue è 1-10 senza il 5 (esercizi 24 e 33).
  5. Un boolean: true o false. Per esempio 15 > 10 vale true (esercizio 1).
  6. = assegna, == confronta. x = 5 mette 5 in x; x == 5 chiede "x vale 5?" e dà un boolean. Scrivere if (x = 5) con un int non compila: incompatible types: int cannot be converted to boolean.
  7. AND logico: è vero solo se entrambe le condizioni sono vere. Se la prima è falsa Java non valuta nemmeno la seconda (valutazione "a corto circuito"). Esempio: eta >= 18 && badge.
  8. OR logico: è vero se almeno una condizione è vera (falso solo se sono false entrambe). Se la prima è vera la seconda non viene valutata. Esempio: giorno == 6 || giorno == 7.
  9. NOT: inverte un boolean: !true è false e viceversa. if (!piove) = "se non piove".
  10. Quando una condizione ha senso solo se un'altra è già vera (condizioni dipendenti): il badge si controlla solo per chi ha almeno 18 anni. Permette di dare un messaggio diverso per ogni motivo (esercizio 7).
  11. Quando bisogna scegliere tra due valori da assegnare o stampare, con una condizione semplice: String s = eta >= 18 ? "Maggiorenne" : "Minorenne";. Se nei due casi bisogna fare cose diverse (più istruzioni), è meglio l'if...else.
  12. Quando si confronta una variabile con tanti valori specifici (1, 2, 3… oppure "A", "B"), come le voci di un menu o i giorni della settimana. Non va bene per gli intervalli (voto >= 6): lì servono gli else if.
  13. L'esecuzione "cade" nei case successivi (fall-through): vengono eseguite anche le istruzioni dei case sotto, fino al primo break o alla fine dello switch. Provato: con n = 2 e nessun break, uno switch con case 1 "Uno", case 2 "Due", case 3 "Tre" e default "Altro" stampa Due, Tre, Altro.
  14. Restituisce il valore assoluto, cioè il numero senza segno: Math.abs(-15) = 15. Serve per le distanze: Math.abs(a - b) (esercizio 11).
  15. Restituiscono il più piccolo e il più grande di due valori: Math.min(14, -3) = -3, Math.max(14, -3) = 14. Usati in un ciclo aggiornano minimo e massimo: max = Math.max(max, x) (esercizio 29).
  16. Un double: la base elevata all'esponente. Math.pow(9, 2) = 81.0, anche se 9 e 2 sono interi.
  17. Un double: la radice quadrata. Math.sqrt(9) = 3.0; Math.sqrt(2) = 1.4142135623730951; con un negativo dà NaN.
  18. È la costante π (3.141592653589793) già pronta, più precisa di scrivere 3.14. Si usa senza parentesi perché non è un metodo: Math.PI * Math.pow(r, 2).
  19. Perché la sua condizione non diventa mai falsa. Le cause tipiche: dimenticare di aggiornare la variabile di controllo (esercizio 30), aggiornarla nel verso sbagliato (i-- invece di i++), una condizione sempre vera come while (true) senza break (esercizio 32), oppure leggere l'input fuori dal ciclo invece che dentro.
  20. Un ciclo annidato è un ciclo dentro un altro: per ogni giro dell'esterno, l'interno fa tutti i suoi giri, quindi i giri totali si moltiplicano (4 × 5 = 20 stelle, 10 × 10 = 100 righe di tabelline). Un ciclo normale ripete una sola dimensione; quello annidato serve per le strutture a due dimensioni: righe e colonne, tabelle, griglie.
