Classroom: la classe Automobile

L'esercitazione pratica dell'ultima slide della lezione "Programmazione a Oggetti in Java": costruire la classe Automobile con attributi, costruttori in overload, metodi e un array di oggetti. Qui la svolgiamo a tappe, un pezzo alla volta, e poi rispondiamo a qualche domanda sui punti in cui si sbaglia più spesso. La teoria è nel capitolo Java: programmazione a oggetti.

Come usare questa paginaLeggi la consegna (è quella della slide), poi affronta le tappe nell'ordine: ognuna aggiunge un pezzo e produce un programma che compila e gira. Prova a scrivere ogni tappa da solo prima di aprire la risposta spiegata. L'ultima tappa è l'esercitazione completa. Ogni programma è stato compilato ed eseguito con Java 21: l'output che vedi è quello vero.

La consegna

Il testo della slide, così come è stato assegnato:

Svolgimento a tappe

Ripasso lampoGli attributi si dichiarano nel corpo della classe, fuori dai metodi. Il costruttore ha lo stesso nome della classe e nessun tipo di ritorno; this.marca è l'attributo, marca il parametro. Teoria: Creare una classe e gli attributi, Il costruttore e la parola chiave this.
01Tappa 1 · Attributi e primo costruttore facile

Consegna. Scrivi la classe Automobile con i quattro attributi della slide e il costruttore senza parametri Automobile(). Nel main crea un'automobile e stampa i suoi attributi, per controllare che tutto compili.

Risposta spiegata

Ragionamento

  1. Gli attributi sono le "caratteristiche" di ogni auto: li scrivo in cima alla classe, fuori da qualsiasi metodo, con i tipi esatti della slide. velocita senza accento: nei nomi Java è meglio non usare lettere accentate.
  2. Il costruttore vuoto non riceve dati, quindi decido io i valori di partenza: marca e modello "Sconosciuta"/"Sconosciuto", anno 0, velocità 0 (l'auto nasce ferma).
  3. Qui this. non sarebbe obbligatorio (non ci sono parametri con lo stesso nome), ma lo scrivo lo stesso: rende chiaro che sto riempiendo gli attributi di questo oggetto.

Codice

public class Automobile {
    // attributi: cosa "è" un'automobile
    String marca;
    String modello;
    int anno;
    double velocita;

    // costruttore vuoto: l'auto nasce con valori di partenza
    Automobile() {
        this.marca = "Sconosciuta";
        this.modello = "Sconosciuto";
        this.anno = 0;
        this.velocita = 0;
    }

    public static void main(String[] args) {
        Automobile a = new Automobile();
        System.out.println(a.marca + " " + a.modello + " " + a.anno + " " + a.velocita);
    }
}

Output

Sconosciuta Sconosciuto 0 0.0

Perché funziona

new Automobile() crea l'oggetto e esegue automaticamente il costruttore, che riempie i quattro attributi. La velocità esce come 0.0 perché è un double: anche assegnando 0, Java lo converte in 0.0.

02Tappa 2 · Gli altri due costruttori, in overload, con this facile

Consegna. Aggiungi i costruttori Automobile(marca, modello) e Automobile(marca, modello, anno), usando this. Nel main crea tre automobili, una per costruttore, e stampa marca, modello e anno di ognuna.

Risposta spiegata

Ragionamento

  1. La slide scrive i parametri senza tipo: li deduco dagli attributi. marca e modello sono String, anno è int.
  2. Chiamo i parametri come gli attributi: è la situazione per cui serve this. this.marca = marca; si legge "l'attributo marca di questo oggetto riceve il parametro marca".
  3. Gli attributi che il costruttore non riceve li inizializzo comunque: con due parametri l'anno non è noto e lo metto a 0; la velocità parte sempre da 0.
  4. Tre costruttori con lo stesso nome ma un numero di parametri diverso (0, 2, 3): è l'overload. Java sceglie quale eseguire guardando gli argomenti di new.

Codice

public class Automobile {
    String marca;
    String modello;
    int anno;
    double velocita;

    // 1 · nessun parametro
    Automobile() {
        this.marca = "Sconosciuta";
        this.modello = "Sconosciuto";
        this.anno = 0;
        this.velocita = 0;
    }

    // 2 · marca e modello: l'anno non lo sappiamo
    Automobile(String marca, String modello) {
        this.marca = marca;        // attributo = parametro
        this.modello = modello;
        this.anno = 0;
        this.velocita = 0;
    }

    // 3 · marca, modello e anno
    Automobile(String marca, String modello, int anno) {
        this.marca = marca;
        this.modello = modello;
        this.anno = anno;
        this.velocita = 0;
    }

    public static void main(String[] args) {
        Automobile a = new Automobile();                         // costruttore 1
        Automobile b = new Automobile("BMW", "Serie 1");         // costruttore 2
        Automobile c = new Automobile("Fiat", "Panda", 2020);    // costruttore 3
        System.out.println(a.marca + " " + a.modello + " " + a.anno);
        System.out.println(b.marca + " " + b.modello + " " + b.anno);
        System.out.println(c.marca + " " + c.modello + " " + c.anno);
    }
}

Output

Sconosciuta Sconosciuto 0
BMW Serie 1 0
Fiat Panda 2020

Perché funziona

  • new Automobile("BMW", "Serie 1") ha 2 argomenti di tipo String: l'unico costruttore che corrisponde è il secondo. Con 3 argomenti (String, String, int) Java usa il terzo.
  • Il costruttore vuoto l'abbiamo scritto noi nella tappa 1, ed è un bene: appena una classe ha almeno un costruttore scritto da noi, Java non regala più quello vuoto. Senza di lui, new Automobile() non compilerebbe. Teoria: Overload dei costruttori.
03Tappa 3 · I metodi accelera, frena e stampaInfo medio

Consegna. Aggiungi i tre metodi accelera(incremento), frena(decremento) e stampaInfo(). Nel main crea una Fiat Panda del 2020, falla accelerare e frenare più volte e chiama stampaInfo() dopo ogni operazione.

Risposta spiegata

Ragionamento

  1. I tre metodi non restituiscono niente: cambiano l'oggetto o stampano. Quindi sono void.
  2. incremento e decremento sono velocità, quindi double come l'attributo velocita.
  3. accelera somma l'incremento alla velocità attuale. frena sottrae, ma una macchina che frena si ferma, non va "sotto zero": se il risultato è negativo lo riporto a 0 (lo spieghiamo nella domanda 08).
  4. stampaInfo scrive tutto su una riga. Un piccolo extra: se anno vale 0 (cioè non è stato indicato nel costruttore) scrivo "anno non indicato" invece di "anno 0".
  5. Nei metodi non serve this: i parametri si chiamano incremento/decremento, non velocita, quindi non c'è ambiguità.

Codice

Attributi e costruttori restano quelli della tappa 2; qui sotto la parte nuova (i tre metodi) e il nuovo main, da mettere al posto di quello di prima.

    // aumenta la velocità
    void accelera(double incremento) {
        velocita = velocita + incremento;
    }

    // diminuisce la velocità, ma non sotto zero
    void frena(double decremento) {
        velocita = velocita - decremento;
        if (velocita < 0) {
            velocita = 0;
        }
    }

    // stampa tutte le informazioni su una riga
    void stampaInfo() {
        String annoTesto;
        if (anno == 0) {
            annoTesto = "anno non indicato";
        } else {
            annoTesto = "anno " + anno;
        }
        System.out.println(marca + " " + modello + " (" + annoTesto + ") - velocità: " + velocita + " km/h");
    }

    public static void main(String[] args) {
        Automobile c = new Automobile("Fiat", "Panda", 2020);
        c.stampaInfo();
        c.accelera(50);
        c.stampaInfo();
        c.accelera(30.5);
        c.stampaInfo();
        c.frena(20);
        c.stampaInfo();
        c.frena(100);        // 60.5 - 100 sarebbe negativo
        c.stampaInfo();
    }
}

Output

Fiat Panda (anno 2020) - velocità: 0.0 km/h
Fiat Panda (anno 2020) - velocità: 50.0 km/h
Fiat Panda (anno 2020) - velocità: 80.5 km/h
Fiat Panda (anno 2020) - velocità: 60.5 km/h
Fiat Panda (anno 2020) - velocità: 0.0 km/h

Prova a mano

ChiamataCalcolovelocita dopo
(appena creata)costruttore0.0
accelera(50)0 + 5050.0
accelera(30.5)50 + 30.580.5
frena(20)80.5 − 2060.5
frena(100)60.5 − 100 = −39.5 → riportata a 00.0

Lo stesso oggetto c "ricorda" la sua velocità tra una chiamata e l'altra: è un attributo, e vive quanto l'oggetto. Teoria: I metodi: cosa può fare un oggetto.

04Tappa 4 · Il main con l'array e il for-each medio

Consegna. Nel main crea Automobile[] auto = new Automobile[3];, riempi le tre caselle (prima casella: new Automobile("Fiat", "Panda", 2020)) e stampa tutte le auto con un ciclo for-each.

Risposta spiegata

Ragionamento

  1. new Automobile[3] crea un array di 3 caselle vuote (valgono null), non 3 automobili. Le auto vanno create una per una con new Automobile(...).
  2. Per le tre caselle uso apposta i tre costruttori diversi: così l'output mostra che funzionano tutti.
  3. Il for-each for (Automobile a : auto) si legge "per ogni automobile a dentro auto": a ogni giro a è la casella successiva, e su di lei chiamo stampaInfo().

Codice

Classe uguale alla tappa 3; cambia solo il main:

    public static void main(String[] args) {
        // 3 caselle vuote (null), non 3 automobili!
        Automobile[] auto = new Automobile[3];

        // riempio TUTTE le caselle, usando i tre costruttori
        auto[0] = new Automobile("Fiat", "Panda", 2020);
        auto[1] = new Automobile("BMW", "Serie 1");
        auto[2] = new Automobile();

        // for-each: a prende a turno ogni automobile dell'array
        for (Automobile a : auto) {
            a.stampaInfo();
        }
    }
}

Output

Fiat Panda (anno 2020) - velocità: 0.0 km/h
BMW Serie 1 (anno non indicato) - velocità: 0.0 km/h
Sconosciuta Sconosciuto (anno non indicato) - velocità: 0.0 km/h

Perché funziona

Tutte e tre le caselle sono state riempite prima del ciclo, quindi ogni a è un oggetto vero. Se una casella restasse null il programma si fermerebbe: lo vediamo nella domanda 07. Teoria: Array di oggetti.

05Tappa 5 · L'esercitazione completa completo

Consegna. Metti insieme tutte le tappe in un unico programma: la classe con attributi, tre costruttori e tre metodi; nel main l'array di tre auto, una prima stampa con il for-each, poi fai accelerare e frenare le auto e stampale di nuovo. Come piccolo extra, trova e stampa l'auto più veloce.

Risposta spiegata

Ragionamento

  1. La classe è quella costruita nelle tappe 1–3, senza cambiamenti.
  2. Nel main: creo l'array e lo riempio (tappa 4), stampo con il for-each (tutte ferme), poi chiamo accelera e frena su caselle diverse e ristampo.
  3. Per la BMW faccio apposta una frenata più forte della velocità, per vedere al lavoro il controllo in frena.
  4. Per l'auto più veloce uso il solito schema del massimo: parto dalla prima, scorro tutte e se ne trovo una con velocità maggiore la tengo. La variabile piuVeloce è un riferimento a un'automobile, non una copia.

Codice

public class Automobile {
    String marca;
    String modello;
    int anno;
    double velocita;

    // 1 · nessun parametro
    Automobile() {
        this.marca = "Sconosciuta";
        this.modello = "Sconosciuto";
        this.anno = 0;
        this.velocita = 0;
    }

    // 2 · marca e modello: l'anno non lo sappiamo
    Automobile(String marca, String modello) {
        this.marca = marca;        // attributo = parametro
        this.modello = modello;
        this.anno = 0;
        this.velocita = 0;
    }

    // 3 · marca, modello e anno
    Automobile(String marca, String modello, int anno) {
        this.marca = marca;
        this.modello = modello;
        this.anno = anno;
        this.velocita = 0;
    }

    // aumenta la velocità
    void accelera(double incremento) {
        velocita = velocita + incremento;
    }

    // diminuisce la velocità, ma non sotto zero
    void frena(double decremento) {
        velocita = velocita - decremento;
        if (velocita < 0) {
            velocita = 0;
        }
    }

    // stampa tutte le informazioni su una riga
    void stampaInfo() {
        String annoTesto;
        if (anno == 0) {
            annoTesto = "anno non indicato";
        } else {
            annoTesto = "anno " + anno;
        }
        System.out.println(marca + " " + modello + " (" + annoTesto + ") - velocità: " + velocita + " km/h");
    }

    public static void main(String[] args) {
        Automobile[] auto = new Automobile[3];
        auto[0] = new Automobile("Fiat", "Panda", 2020);
        auto[1] = new Automobile("BMW", "Serie 1");
        auto[2] = new Automobile();

        System.out.println("=== Parcheggio: tutte ferme ===");
        for (Automobile a : auto) {
            a.stampaInfo();
        }

        // un po' di movimento
        auto[0].accelera(50);
        auto[0].accelera(70);      // 50 + 70 = 120
        auto[0].frena(30);         // 120 - 30 = 90
        auto[1].accelera(40);
        auto[1].frena(100);        // 40 - 100 sarebbe -60: resta 0
        auto[2].accelera(25.5);

        System.out.println("=== Dopo accelerazioni e frenate ===");
        for (Automobile a : auto) {
            a.stampaInfo();
        }

        // chi va più veloce? (un for-each che cerca il massimo)
        Automobile piuVeloce = auto[0];
        for (Automobile a : auto) {
            if (a.velocita > piuVeloce.velocita) {
                piuVeloce = a;
            }
        }
        System.out.println("La più veloce è la " + piuVeloce.marca + " " + piuVeloce.modello
                + " a " + piuVeloce.velocita + " km/h");
    }
}

Output

=== Parcheggio: tutte ferme ===
Fiat Panda (anno 2020) - velocità: 0.0 km/h
BMW Serie 1 (anno non indicato) - velocità: 0.0 km/h
Sconosciuta Sconosciuto (anno non indicato) - velocità: 0.0 km/h
=== Dopo accelerazioni e frenate ===
Fiat Panda (anno 2020) - velocità: 90.0 km/h
BMW Serie 1 (anno non indicato) - velocità: 0.0 km/h
Sconosciuta Sconosciuto (anno non indicato) - velocità: 25.5 km/h
La più veloce è la Fiat Panda a 90.0 km/h

Perché funziona

  • Ogni oggetto ha i suoi attributi: accelerare auto[0] non cambia la velocità di auto[1]. Il metodo accelera è uno solo, ma lavora sull'oggetto su cui è stato chiamato.
  • Fiat: 0 + 50 + 70 − 30 = 90. BMW: 0 + 40 − 100 = −60, riportata a 0. Terza auto: 0 + 25.5 = 25.5. Quindi la più veloce è la Fiat.
  • Dentro il ciclo del massimo uso a.velocita e piuVeloce.velocita: dal main gli attributi si raggiungono con l'operatore punto, come nella teoria (Creare oggetti e accedere agli attributi).

Rispetto alla slide

Tutti i requisiti della consegna sono presenti: 4 attributi con i tipi giusti, 3 costruttori con this, 3 metodi, array di 3 elementi con la Fiat Panda del 2020 nella prima casella, stampa con for-each. Sono aggiunte nostre: il controllo "mai sotto zero" in frena, "anno non indicato" in stampaInfo, la seconda stampa e la ricerca dell'auto più veloce.

Domande sull'esercitazione

Ripasso lampoTre errori tipici di questa esercitazione: dimenticare this, lasciare una casella dell'array a null, non controllare i valori che entrano in un metodo. Teoria: this, Array di oggetti, Scope delle variabili.
06Cosa succede senza this? domande

Consegna. Nel costruttore con tre parametri togliamo this., così:

    // 3 · marca, modello e anno
    Automobile(String marca, String modello, int anno) {
        marca = marca;          // manca this.
        modello = modello;      // manca this.
        anno = anno;            // manca this.
        this.velocita = 0;
    }

Il programma compila? Cosa stampa System.out.println(c.marca + " " + c.modello + " " + c.anno); dopo Automobile c = new Automobile("Fiat", "Panda", 2020);? Perché?

Risposta spiegata

Risposta

Compila senza errori, ma stampa:

null null 0

Spiegazione

  1. Dentro il costruttore esistono due cose che si chiamano marca: l'attributo e il parametro. Vince quella più vicina, cioè il parametro (è lo scope: il parametro "copre" l'attributo).
  2. Quindi marca = marca; vuol dire "parametro = parametro": il parametro viene assegnato a se stesso e l'attributo non viene toccato.
  3. Gli attributi restano al loro valore iniziale: null per le String, 0 per l'int. Ecco null null 0.
  4. È un errore subdolo proprio perché il compilatore non dice niente. La correzione è rimettere this.: this.marca = marca;. In alternativa si possono dare ai parametri nomi diversi (m, mod, a), ma la slide chiede di usare this.
07Una casella dell'array resta null domande

Consegna. Nel main della tappa 5 ci dimentichiamo di riempire l'ultima casella:

    public static void main(String[] args) {
        Automobile[] auto = new Automobile[3];
        auto[0] = new Automobile("Fiat", "Panda", 2020);
        auto[1] = new Automobile("BMW", "Serie 1");
        // auto[2] dimenticata!

        for (Automobile a : auto) {
            a.stampaInfo();
        }
    }
}

Cosa succede quando si esegue? Che errore dà Java e come si corregge?

Risposta spiegata

Risposta

Il programma compila, stampa le prime due auto e poi si ferma con una NullPointerException. Output vero (classe completa della tappa 5 con questo main):

Fiat Panda (anno 2020) - velocità: 0.0 km/h
BMW Serie 1 (anno non indicato) - velocità: 0.0 km/h
Exception in thread "main" java.lang.NullPointerException: Cannot invoke "Automobile.stampaInfo()" because "<local5>" is null
	at Automobile.main(Automobile.java:62)

Spiegazione

  1. new Automobile[3] crea 3 caselle che valgono null. Le prime due le abbiamo riempite, la terza è rimasta null: "nessun oggetto".
  2. Al terzo giro del for-each a vale null, e a.stampaInfo() chiede di eseguire un metodo su un oggetto che non c'è. Java non può farlo e lancia l'eccezione.
  3. Come si legge il messaggio: Cannot invoke "Automobile.stampaInfo()" because "<local5>" is null = "non posso chiamare stampaInfo() perché la variabile è null". La riga at Automobile.main(Automobile.java:62) dice dove: riga 62 del file, cioè proprio a.stampaInfo();.
  4. <local5> è il modo in cui Java chiama la variabile locale numero 5 quando il programma è compilato senza informazioni di debug. Compilando con javac -g Automobile.java il messaggio mostra il nome vero: because "a" is null. Molti editor compilano già con -g, quindi lì vedi direttamente "a".

Come si corregge

  • La soluzione giusta: riempire tutte le caselle prima del ciclo, per esempio auto[2] = new Automobile();.
  • Se l'array può avere caselle vuote (per esempio un parcheggio con posti liberi), si controlla prima di usare l'elemento:
for (Automobile a : auto) {
    if (a != null) {        // salta le caselle vuote
        a.stampaInfo();
    }
}
08Perché frena non deve andare sotto zero? domande

Consegna. Scriviamo frena nel modo più semplice, senza controllo:

    // versione SENZA controllo
    void frena(double decremento) {
        velocita = velocita - decremento;   // nessun controllo
    }

Cosa stampa questo frammento? Perché è un problema, e perché il controllo va messo dentro il metodo e non nel main?

Automobile b = new Automobile("BMW", "Serie 1");
b.accelera(40);
b.frena(100);
b.stampaInfo();
Risposta spiegata

Risposta

BMW Serie 1 (anno non indicato) - velocità: -60.0 km/h

Spiegazione

  1. 40 − 100 = −60: Java fa il conto senza problemi e l'auto finisce con una velocità di −60 km/h. Nella realtà non ha senso: frenando un'auto rallenta fino a fermarsi, non comincia ad andare all'indietro.
  2. Un oggetto dovrebbe essere sempre in uno stato valido. Se la velocità diventa negativa, tutto quello che viene dopo sbaglia: stampaInfo scrive un valore assurdo, la ricerca dell'auto più veloce potrebbe dare risultati strani, un successivo accelera(30) porterebbe la velocità a −30 invece che a 30.
  3. Per questo il controllo va dentro frena: se il risultato è negativo, la velocità torna a 0. Così è il metodo stesso a garantire che la velocità non sia mai negativa, comunque lo si chiami. Se lo mettessimo nel main, bisognerebbe ricordarsi di ripeterlo dopo ogni chiamata a frena, in ogni programma che usa la classe.
  4. Con la versione della tappa 3 lo stesso frammento stampa velocità: 0.0 km/h (si vede nell'output della tappa 5, riga della BMW). È un'aggiunta nostra: la slide non lo chiede esplicitamente, ma rende il modello realistico. Con lo stesso ragionamento si potrebbe rifiutare un incremento negativo in accelera.
