Il mattone comune: leggere un file riga per riga

Tutti e tre i progetti leggono dei file di testo in cui ogni riga è un dato (un libro, un prodotto, una partita). FileReader però legge un carattere alla volta, non una riga. Prima dei progetti, quindi, costruiamo un metodo che rimette insieme le righe: lo copieremo uguale in tutti e tre. Teoria: Leggere un file con FileReader.

01Tappa · Il metodo leggiRighe medio

Consegna. Scrivi un metodo

static ArrayList<String> leggiRighe(String nomeFile) throws IOException

che legge il file carattere per carattere con FileReader e restituisce una lista con una stringa per ogni riga. Requisiti:

  1. il carattere '\n' (a capo) chiude la riga corrente e ne comincia una nuova;
  2. il carattere '\r' va ignorato: i file salvati su Windows finiscono ogni riga con \r\n, e senza questo controllo le righe avrebbero un carattere invisibile in fondo;
  3. anche l'ultima riga va salvata se il file non finisce con un "a capo";
  4. il file va chiuso sempre, anche se la lettura fallisce: usa finally.

Il main prova il metodo su due file: spesa.txt (salvato da Windows, tre righe, l'ultima senza "a capo") e compiti.txt, che non esiste. Per ogni riga stampa il numero, il testo e quanti caratteri contiene; se il file non c'è stampa un messaggio con due catch distinti per FileNotFoundException e IOException.

Soluzione spiegata

Ragionamento

  1. Un accumulatore di testo. Tengo una stringa riga che parte vuota. Per ogni carattere letto: se è '\n' la riga è finita, la aggiungo alla lista e riparto da ""; altrimenti attacco il carattere in fondo con riga = riga + (char) c. È lo stesso schema dell'accumulatore della somma, ma con il testo.
  2. Il ciclo di lettura è quello del capitolo: leggo una volta prima del while, controllo != -1 (fine del file), e leggo di nuovo come ultima istruzione del giro.
  3. L'ultima riga. Se il file non finisce con '\n', quando arriva il -1 nella variabile riga c'è ancora uova, mai salvata: dopo il ciclo, se non è vuota, la aggiungo.
  4. try-finally. Il metodo non sa cosa fare se la lettura fallisce (stampare? riprovare?), quindi non cattura l'eccezione: la dichiara con throws IOException e la lascia a chi lo chiama. Però il file deve essere chiuso comunque: per questo close() è nel finally, in un try senza catch. Teoria: finally per chiudere un file.
  5. Nel main IOException è checked: il compilatore obbliga a gestirla. I due catch vanno dal più specifico (FileNotFoundException) al più generale (IOException).

Codice

import java.io.FileNotFoundException;
import java.io.FileReader;
import java.io.IOException;
import java.util.ArrayList;

public class LeggiRighe {

    static ArrayList<String> leggiRighe(String nomeFile) throws IOException {
        ArrayList<String> righe = new ArrayList<>();
        FileReader lettore = new FileReader(nomeFile);   // FileNotFoundException se non c'è
        try {
            String riga = "";
            int c = lettore.read();
            while (c != -1) {
                if (c == '\n') {            // fine riga: la salvo e ne comincio un'altra
                    righe.add(riga);
                    riga = "";
                } else if (c != '\r') {     // '\r' lo mette Windows prima di '\n': lo ignoro
                    riga = riga + (char) c;
                }
                c = lettore.read();
            }
            if (riga.length() > 0) {        // ultima riga senza "a capo"
                righe.add(riga);
            }
        } finally {
            lettore.close();                // eseguito sempre, anche se read() fallisce
        }
        return righe;
    }

    public static void main(String[] args) {
        String[] nomi = {"spesa.txt", "compiti.txt"};
        for (String nome : nomi) {
            System.out.println("== " + nome);
            try {
                ArrayList<String> righe = leggiRighe(nome);
                for (int i = 0; i < righe.size(); i++) {
                    String r = righe.get(i);
                    System.out.println((i + 1) + ") " + r + " [" + r.length() + " caratteri]");
                }
                System.out.println("Righe lette: " + righe.size());
            } catch (FileNotFoundException e) {
                System.out.println("Il file non c'è: " + e.getMessage());
            } catch (IOException e) {
                System.out.println("Errore di lettura: " + e.getMessage());
            }
        }
    }
}

Cosa dice l'output

  • Ogni riga ha il numero di caratteri giusto (latte 5, pane 4): il '\r' è stato davvero scartato. Senza il controllo, le prime due righe avrebbero 6 e 5 caratteri e "latte".equals(riga) sarebbe false.
  • uova c'è, anche se dopo non c'era un "a capo".
  • Per compiti.txt è new FileReader(...) a lanciare FileNotFoundException: il try del metodo non è ancora cominciato, quindi non c'è niente da chiudere. Il messaggio tra parentesi dipende dal sistema operativo: su Windows è in italiano.

02Tappa · Da una riga di testo a un oggetto medio

Consegna. Una riga di catalogo può avere due campi (codice;titolo, e allora il libro ha 1 copia) oppure tre (codice;titolo;copie).

  1. Scrivi la classe Libro con gli attributi codice, titolo, copie e due costruttori (con 2 e con 3 parametri), che usano this; aggiungi un metodo descrizione().
  2. Scrivi un metodo static Libro creaLibro(String riga) che divide la riga con split(";") e chiama il costruttore giusto. Se i campi non sono 2 o 3, lancia una IllegalArgumentException con un messaggio che spiega il problema.
  3. Nel main, a partire dall'array
String[] righe = {"L01;Cuore;2", "L02;Dune", "L03;Il Gattopardo;tre", "L04", "L05;Lessico famigliare;1"};

crea i libri validi in un ArrayList<Libro>; per le righe sbagliate stampa un messaggio diverso se il numero di copie non è un numero o se i campi sono sbagliati. Alla fine stampa i libri caricati.

Output atteso:

Soluzione spiegata

Ragionamento

  1. split. riga.split(";") restituisce un array di stringhe, uno per campo (l'hai già incontrato negli esercizi sulla HashMap). Con parti.length so quanti campi ci sono.
  2. Overload dei costruttori. 2 campi → new Libro(codice, titolo); 3 campi → new Libro(codice, titolo, copie). Java sceglie il costruttore dal numero di argomenti. Teoria: Overload dei costruttori.
  3. Due errori diversi. "tre" non è un numero: ci pensa Integer.parseInt a lanciare NumberFormatException. Il numero di campi sbagliato invece per Java non è un errore: siamo noi a lanciarlo con throw new IllegalArgumentException(...).
  4. L'ordine dei catch. NumberFormatException è una "figlia" di IllegalArgumentException (un numero scritto male è un caso particolare di argomento non valido). Quindi il suo catch va prima: altrimenti quello generale prenderebbe tutto.
  5. Il try dentro il for. Il try sta dentro il ciclo: se una riga è sbagliata si salta solo quella e il ciclo continua con la successiva. Se il try fosse fuori dal for, il primo errore fermerebbe tutto il caricamento.

Codice

import java.util.ArrayList;

class Libro {
    String codice;
    String titolo;
    int copie;

    Libro(String codice, String titolo) {
        this.codice = codice;
        this.titolo = titolo;
        this.copie = 1;
    }

    Libro(String codice, String titolo, int copie) {
        this.codice = codice;
        this.titolo = titolo;
        this.copie = copie;
    }

    String descrizione() {
        return codice + " " + titolo + ", copie: " + copie;
    }
}

public class ProvaLibri {

    static Libro creaLibro(String riga) {
        String[] parti = riga.split(";");
        if (parti.length == 2) {
            return new Libro(parti[0], parti[1]);
        }
        if (parti.length == 3) {
            return new Libro(parti[0], parti[1], Integer.parseInt(parti[2]));
        }
        throw new IllegalArgumentException("servono 2 o 3 campi, ne ho trovati " + parti.length);
    }

    public static void main(String[] args) {
        String[] righe = {"L01;Cuore;2", "L02;Dune", "L03;Il Gattopardo;tre", "L04", "L05;Lessico famigliare;1"};
        ArrayList<Libro> libri = new ArrayList<>();

        for (String riga : righe) {
            try {
                libri.add(creaLibro(riga));
            } catch (NumberFormatException e) {
                System.out.println("\"" + riga + "\" scartata: le copie non sono un numero");
            } catch (IllegalArgumentException e) {
                System.out.println("\"" + riga + "\" scartata: " + e.getMessage());
            }
        }

        System.out.println("Libri caricati: " + libri.size());
        for (Libro l : libri) {
            System.out.println("  " + l.descrizione());
        }
    }
}

E se inverto i due catch?

Se metto prima catch (IllegalArgumentException e) e poi catch (NumberFormatException e), il programma non compila:

riga 8: error: exception NumberFormatException has already been caught

"has already been caught" = è già stata catturata: il primo catch prende anche le NumberFormatException, quindi il secondo non verrebbe mai eseguito. Regola: dal più specifico al più generale. Teoria: Gestire più eccezioni.

Passo 2 · La classe Libro

Gli attributi sono i sostantivi della consegna (codice, titolo, autore, copie, prenotazioni), i metodi sono i verbi (prestare, restituire, descrivere). I due costruttori differiscono per il numero di parametri: in tutti e due this.codice = codice distingue l'attributo dal parametro con lo stesso nome. L'attributo prenotazioni viene creato direttamente nella dichiarazione (= new LinkedList<>()): così ogni libro nasce con la sua coda, vuota, qualunque costruttore si usi.

void presta() {
    if (copie == 0) {
        throw new IllegalStateException("nessuna copia di " + titolo + " sullo scaffale");
    }
    copie--;
}

void restituisci() {
    if (copie == copieTotali) {
        throw new IllegalStateException("tutte le copie di " + titolo + " sono già in biblioteca");
    }
    copie++;
}

Perché due attributi per le copie? copie cambia con i prestiti, copieTotali no: serve a capire quando una restituzione è impossibile (non si possono avere 4 copie di un libro che ne ha 3). In quel caso, e quando si presta un libro senza copie, il metodo lancia un'eccezione: l'oggetto si rifiuta di finire in uno stato assurdo. IllegalStateException è unchecked, quindi non serve throws nell'intestazione.

Passo 3 · Il registro: elimina, poi aggiungi in fondo

All'avvio registro.txt esiste (è quello della settimana scorsa): con exists() lo scopro e con delete() lo cancello. Poi ogni chiamata di registra apre il file con new FileWriter("registro.txt", true): il true è la modalità append. Senza, ogni apertura svuoterebbe il file e alla fine il registro conterrebbe solo l'ultima riga.

static void registra(String testo) {
    try {
        FileWriter w = new FileWriter("registro.txt", true);   // true = scrivi in fondo
        w.write(testo + "\n");
        w.close();
    } catch (IOException e) {
        System.out.println("Impossibile scrivere nel registro: " + e.getMessage());
    }
}

static void registra(String azione, Libro l, String studente) {
    registra(azione + " " + l.codice + " a " + studente);
}

È un overload: stesso nome, parametri diversi (uno contro tre). La versione con tre parametri non riscrive il codice del file: prepara il testo e chiama l'altra. registra gestisce da sé la sua IOException con un catch: se il registro non si può scrivere, il programma avvisa ma continua a prestare libri.

Passo 4 · Caricare il catalogo

creaLibro è quello della tappa, con un campo in più (3 o 4 campi). Nel main il try esterno gestisce la IOException di leggiRighe (checked: senza, non compila), quello interno le righe sbagliate (unchecked: non obbligatorie, ma senza il programma si fermerebbe alla riga 5).

try {
    ArrayList<String> righe = leggiRighe("catalogo.txt");
    for (int i = 0; i < righe.size(); i++) {
        try {
            Libro l = creaLibro(righe.get(i));
            catalogo.put(l.codice, l);
            elenco.add(l);
        } catch (NumberFormatException e) {
            System.out.println("Riga " + (i + 1) + " saltata, copie non numeriche: " + e.getMessage());
        } catch (IllegalArgumentException e) {
            System.out.println("Riga " + (i + 1) + " saltata: " + e.getMessage());
        }
    }
} catch (IOException e) {
    System.out.println("Errore nella lettura del catalogo: " + e.getMessage());
    return;
}
System.out.println("Libri caricati: " + catalogo.size());

Uso il for classico perché mi serve il numero della riga per il messaggio (i + 1, dato che gli indici partono da 0). Ogni libro valido va in due strutture: la mappa per trovarlo dal codice in un attimo, la lista per l'ordine. Non sono due copie del libro: contengono due riferimenti allo stesso oggetto, quindi se un prestito cambia le copie, la modifica si vede da tutte e due.

Per ogni stringa dell'array (foreach) uso split per avere tipo, codice e studente. Prima di tutto controllo containsKey: senza, get restituirebbe null e la prima chiamata di un metodo su quel "libro" darebbe NullPointerException. continue salta al giro successivo del ciclo.

  • La coda. Quando Carla chiede L01 non ci sono copie: offer la mette in fondo alla coda. Quando Anna restituisce, poll toglie e restituisce il primo in coda (FIFO, chi arriva prima è servito prima), e il libro le viene prestato subito.

class Libro {

    String titolo;
    String autore;
    int copieTotali;
    int copie;                                            // copie sullo scaffale adesso
    LinkedList<String> prenotazioni = new LinkedList<>(); // coda: chi aspetta il libro

    Libro(String codice, String titolo, String autore) {

        this.copie = 1;

        }

            String riga = "";

                    riga = "";

                righe.add(riga);
            }

            lettore.close();                // eseguito sempre, anche se read() fallisce

Ragionamento

  1. Perché i centesimi. I double non sanno rappresentare esattamente tutti i decimali: 0.1 + 0.2 dà 0.30000000000000004. Con gli int in centesimi i conti sono sempre esatti; la virgola si mette solo quando si stampa.
  2. Il metodo euro. centesimi / 100 (divisione intera) dà gli euro, centesimi % 100 (il resto) i centesimi. Se i centesimi sono meno di 10 serve uno zero davanti: 5 centesimi si scrivono 05, non 5. Il punto lo scrivo io, quindi il risultato non cambia da un computer all'altro (con printf su un computer in italiano uscirebbe la virgola).
  3. La pila. push mette in cima, pop toglie dalla cima: l'ultimo entrato è il primo a uscire (LIFO). Stampando la LinkedList la cima è il primo elemento a sinistra: guarda [P03, P01]. Teoria: La pila.
  4. Il totale si ricalcola ogni volta scorrendo il carrello con un foreach e chiedendo il prezzo al listino con get.
  5. L'ultimo ANNULLA trova il carrello vuoto: pop() lancia NoSuchElementException (unchecked, va importata da java.util). Lo stesso controllo si poteva fare con un if (carrello.size() > 0): qui usiamo il catch per vedere l'eccezione.

public class Carrello {

    static String euro(int centesimi) {
        String cent = "" + centesimi % 100;
        if (centesimi % 100 < 10) {
            cent = "0" + cent;                 // 5 centesimi -> "05"
        }
        return centesimi / 100 + "." + cent;
    }

    public static void main(String[] args) {
        HashMap<String, Integer> listino = new HashMap<>();
        listino.put("P01", 150);
        listino.put("P02", 80);
        listino.put("P03", 2990);

        LinkedList<String> carrello = new LinkedList<>();   // usata come pila
        String[] azioni = {"P01", "P03", "ANNULLA", "P02", "P02", "ANNULLA", "ANNULLA", "ANNULLA", "ANNULLA"};

        for (String azione : azioni) {
            try {
                if (azione.equals("ANNULLA")) {
                    String tolto = carrello.pop();          // toglie la cima
                    System.out.print("annullo " + tolto + " -> ");
                } else {
                    carrello.push(azione);                  // mette in cima
                    System.out.print("aggiungo " + azione + " -> ");
                }
            } catch (NoSuchElementException e) {
                System.out.print("niente da annullare -> ");
            }
            int totale = 0;
            for (String codice : carrello) {
                totale += listino.get(codice);
            }
            System.out.println(carrello + " totale " + euro(totale) + " euro");
        }

Passo 2 · Prezzi in centesimi

Come nella tappa, i soldi sono int in centesimi.     return (int) Math.round(euro * 100);      // 1.5 -> 150
}

        throw new IllegalArgumentException("quantità non valida: " + q);

    if (q > quantita) {

Due errori diversi, due eccezioni diverse: una quantità come -1 è un argomento sbagliato (IllegalArgumentException); chiedere 2 zaini quando ne resta 1 è una richiesta giusta che lo stato attuale del magazzino non permette (IllegalStateException). class Prodotto {
    String codice;
    String nome;
    int prezzo;       // in centesimi: 1.50 euro -> 150
    int quantita;

    // prodotto appena messo a listino, ancora senza pezzi
    Prodotto(String codice, String nome, int prezzo) {
        this.codice = codice;
        this.nome = nome;
        this.prezzo = prezzo;
        this.quantita = 0;
    }

    Prodotto(String codice, String nome, int prezzo, int quantita) {
        this.codice = codice;
        this.nome = nome;
        this.prezzo = prezzo;
        this.quantita = quantita;
    }

    void preleva(int q) {
        if (q <= 0) {
            throw new IllegalArgumentException("quantità non valida: " + q);
        }
        if (q > quantita) {
            throw new IllegalStateException("di " + nome + " ne restano solo " + quantita);
        }
        quantita -= q;
    }

        quantita += q;
    }

    // ---------- overload: un importo in euro da centesimi o da testo ----------
    static String euro(int centesimi) {
        String cent = "" + centesimi % 100;

            cent = "0" + cent;                 // 5 centesimi -> "05"
        }
        return centesimi / 100 + "." + cent;

    static int centesimi(String testo) {
        double euro = Double.parseDouble(testo);  // "1.50" -> 1.5

    }

    // ---------- overload: scrivere su file, in fondo o da capo ----------
    static void scrivi(String nomeFile, String testo, boolean inFondo) throws IOException {
        FileWriter w = new FileWriter(nomeFile, inFondo);
        try {
            w.write(testo + "\n");
        } finally {
            w.close();
        }
    }

    static void scrivi(String nomeFile, String testo) throws IOException {
        scrivi(nomeFile, testo, true);         // di solito si aggiunge in fondo

    static ArrayList<String> leggiRighe(String nomeFile) throws IOException {
        ArrayList<String> righe = new ArrayList<>();
        FileReader lettore = new FileReader(nomeFile);
        try {
            String riga = "";
            int c = lettore.read();
            while (c != -1) {
                if (c == '\n') {
                    righe.add(riga);
                    riga = "";
                } else if (c != '\r') {
                    riga = riga + (char) c;
                }
                c = lettore.read();
            }
            if (riga.length() > 0) {
                righe.add(riga);
            }
        } finally {
            lettore.close();
        }
        return righe;

        String[] p = riga.split(";");

        }
        if (p.length == 4) {
            return new Prodotto(p[0], p[1], centesimi(p[2]), Integer.parseInt(p[3]));

        throw new IllegalArgumentException("numero di campi sbagliato");

        String[] p = riga.split(";");

06Tappa · Ordinare per estrazione del massimo medio

Consegna. In una HashMap<String, Integer> ci sono i punti di quattro giocatori: Rossi 12, Bianchi 18, Verdi 7, Neri 15. Stampa la mappa, poi stampa la classifica dal primo all'ultimo. Metodo da usare: copia i nomi in un ArrayList, poi ripeti finché la lista non è vuota: trova il giocatore con più punti tra quelli rimasti, toglilo dalla lista e aggiungilo in fondo alla classifica.

Soluzione spiegata

Ragionamento

  1. La HashMap non ha ordine. La prima riga dell'output lo mostra: le coppie non escono né per punti né nell'ordine di inserimento. Per una classifica serve una lista, che l'ordine lo tiene.
  2. new ArrayList<>(punti.keySet()) crea una lista con tutte le chiavi della mappa: i nomi da sistemare.
  3. Cercare il massimo per indice, come la "media più alta" degli esercizi sugli array: migliore parte da 0 e diventa i ogni volta che trovo qualcuno con più punti. Mi serve l'indice, non il nome, perché poi rimasti.remove(migliore) toglie per posizione e restituisce l'elemento tolto: lo passo direttamente a classifica.add.
  4. Il confronto. punti.get(...) restituisce un Integer. Con > Java fa l'unboxing e confronta i numeri: va bene. Con == invece confronterebbe gli oggetti, la trappola dei wrapper.
  5. Ogni giro del while toglie un nome da rimasti, quindi il ciclo finisce sempre. Con 4 giocatori fa 4 giri.

import java.util.ArrayList;
import java.util.HashMap;

public class ClassificaPunti {
    public static void main(String[] args) {
        HashMap<String, Integer> punti = new HashMap<>();
        punti.put("Rossi", 12);
        punti.put("Bianchi", 18);
        punti.put("Verdi", 7);
        punti.put("Neri", 15);
        System.out.println("La HashMap: " + punti);

        ArrayList<String> rimasti = new ArrayList<>(punti.keySet());
        ArrayList<String> classifica = new ArrayList<>();
        while (rimasti.size() > 0) {
            int migliore = 0;
            for (int i = 1; i < rimasti.size(); i++) {
                if (punti.get(rimasti.get(i)) > punti.get(rimasti.get(migliore))) {
                    migliore = i;
                }
            }
            classifica.add(rimasti.remove(migliore));   // remove(i) restituisce l'elemento tolto
        }

        for (int i = 0; i < classifica.size(); i++) {
            String nome = classifica.get(i);
            System.out.println((i + 1) + ". " + nome + " " + punti.get(nome) + " punti");
        }
    }
}

Questo metodo si chiama ordinamento per selezione: è lento con migliaia di elementi, ma per una classifica di qualche squadra va benissimo ed è facile da controllare a mano. Nel progetto lo eviteremo con dei criteri di spareggio.

static Partita creaPartita(String riga, HashMap<String, Squadra> squadre) {
    String[] p = riga.split(";");
    if (p.length != 4) {
        throw new IllegalArgumentException("servono 4 campi, ne ho " + p.length);
    }
    for (int i = 0; i < 2; i++) {
        if (!squadre.containsKey(p[i])) {
            throw new IllegalArgumentException(p[i] + " non è iscritta al torneo");
        }
    }
    if (p[0].equals(p[1])) {
        throw new IllegalArgumentException("una squadra non gioca contro se stessa");
    }
    int[] gol = new int[2];
    for (int i = 0; i < gol.length; i++) {
        gol[i] = Integer.parseInt(p[i + 2]);      // può lanciare NumberFormatException
        if (gol[i] < 0) {
            throw new IllegalArgumentException("gol negativi");
        }
    }
    return new Partita(squadre.get(p[0]), squadre.get(p[1]), gol[0], gol[1]);
}
  • I controlli vanno in un ordine preciso: prima il numero di campi (altrimenti p[3] darebbe ArrayIndexOutOfBoundsException), poi le squadre, poi i gol.
  • I due gol finiscono in un array int[] gol: un solo ciclo li converte e li controlla tutti e due, con gol.length come limite e p[i + 2] per prendere i campi 2 e 3.
  • p[0].equals(p[1]): due stringhe si confrontano con equals.
  • throw interrompe il metodo subito: niente return, niente partita creata. Il messaggio dell'eccezione è il motivo che finirà in scarti.txt.

Passo 7 · La classifica

L'ordinamento è quello della tappa, ma il confronto non è più un semplice >: lo fa il metodo davantiA della squadra.

boolean davantiA(Squadra altra) {
    if (punti != altra.punti) {
        return punti > altra.punti;
    }
    if (differenza() != altra.differenza()) {
        return differenza() > altra.differenza();
    }
    return golFatti > altra.golFatti;
}

Prima i punti; solo se sono uguali la differenza reti; solo se anche quella è uguale i gol fatti. Ogni return esce subito dal metodo. Nel nostro torneo servono gli spareggi: Lupi e Leoni hanno 8 punti, ma i Lupi sono primi con +3 contro +2; Aquile e Tigri hanno 3 punti (le Aquile ne hanno fatti 5, meno 2 di penalizzazione) e le Aquile sono davanti con -2 contro -3. Nessuna coppia di squadre è pari in tutto, quindi la classifica non dipende dall'ordine della HashMap da cui parte la lista (new ArrayList<>(squadre.values())).

import java.io.File;
import java.io.FileReader;
import java.io.FileWriter;
import java.io.IOException;
import java.util.ArrayList;
import java.util.HashMap;
import java.util.LinkedList;
import java.util.Map;

class Squadra {
    String nome;
    int punti;
    int vinte, pareggiate, perse;
    int golFatti, golSubiti;

    Squadra(String nome) {
        this.nome = nome;
        this.punti = 0;
    }

    // per una squadra che parte penalizzata (o con un bonus)
    Squadra(String nome, int punti) {
        this.nome = nome;
        this.punti = punti;
    }

    void registra(int fatti, int subiti) {
        golFatti += fatti;
        golSubiti += subiti;
        if (fatti > subiti) {
            vinte++;
            punti += 3;
        } else if (fatti == subiti) {
            pareggiate++;
            punti += 1;
        } else {
            perse++;
        }
    }

    int giocate() {
        return vinte + pareggiate + perse;
    }

    int differenza() {
        return golFatti - golSubiti;
    }

    // true se questa squadra va messa davanti ad "altra" in classifica
    boolean davantiA(Squadra altra) {
        if (punti != altra.punti) {
            return punti > altra.punti;
        }
        if (differenza() != altra.differenza()) {
            return differenza() > altra.differenza();
        }
        return golFatti > altra.golFatti;
    }

    String rigaClassifica(int posizione) {
        String diff = "" + differenza();
        if (differenza() > 0) {
            diff = "+" + diff;
        }
        return posizione + ". " + nome + " " + punti + " punti (G" + giocate() + " V" + vinte
                + " N" + pareggiate + " P" + perse + ", gol " + golFatti + "-" + golSubiti + ", " + diff + ")";
    }
}

class Partita {
    Squadra casa;
    Squadra ospite;
    int golCasa;
    int golOspite;

    Partita(Squadra casa, Squadra ospite, int golCasa, int golOspite) {
        this.casa = casa;
        this.ospite = ospite;
        this.golCasa = golCasa;
        this.golOspite = golOspite;
    }

    void applica() {                       // aggiorna le due squadre
        casa.registra(golCasa, golOspite);
        ospite.registra(golOspite, golCasa);
    }

    String risultato() {
        return casa.nome + " " + golCasa + " - " + golOspite + " " + ospite.nome;
    }
}

public class Torneo {

    static ArrayList<String> leggiRighe(String nomeFile) throws IOException {
        ArrayList<String> righe = new ArrayList<>();
        FileReader lettore = new FileReader(nomeFile);
        try {
            String riga = "";
            int c = lettore.read();
            while (c != -1) {
                if (c == '\n') {
                    righe.add(riga);
                    riga = "";
                } else if (c != '\r') {
                    riga = riga + (char) c;
                }
                c = lettore.read();
            }
            if (riga.length() > 0) {
                righe.add(riga);
            }
        } finally {
            lettore.close();
        }
        return righe;
    }

    static Squadra creaSquadra(String riga) {
        String[] p = riga.split(";");
        if (p.length == 1) {
            return new Squadra(p[0]);
        }
        return new Squadra(p[0], Integer.parseInt(p[1]));
    }

    // trasforma una riga in una Partita, oppure lancia un'eccezione che spiega perché non si può
    static Partita creaPartita(String riga, HashMap<String, Squadra> squadre) {
        String[] p = riga.split(";");
        if (p.length != 4) {
            throw new IllegalArgumentException("servono 4 campi, ne ho " + p.length);
        }
        for (int i = 0; i < 2; i++) {
            if (!squadre.containsKey(p[i])) {
                throw new IllegalArgumentException(p[i] + " non è iscritta al torneo");
            }
        }
        if (p[0].equals(p[1])) {
            throw new IllegalArgumentException("una squadra non gioca contro se stessa");
        }
        int[] gol = new int[2];
        for (int i = 0; i < gol.length; i++) {
            gol[i] = Integer.parseInt(p[i + 2]);      // può lanciare NumberFormatException
            if (gol[i] < 0) {
                throw new IllegalArgumentException("gol negativi");
            }
        }
        return new Partita(squadre.get(p[0]), squadre.get(p[1]), gol[0], gol[1]);
    }

    static void scarta(String riga, String motivo) {
        try {
            FileWriter w = new FileWriter("scarti.txt", true);   // in fondo, senza cancellare
            w.write(riga + "  <-- " + motivo + "\n");
            w.close();
        } catch (IOException e) {
            System.out.println("Non riesco a scrivere scarti.txt");
        }
    }

    // estrae ogni volta la squadra migliore tra quelle rimaste
    static ArrayList<Squadra> ordina(ArrayList<Squadra> daOrdinare) {
        ArrayList<Squadra> classifica = new ArrayList<>();
        while (daOrdinare.size() > 0) {
            int migliore = 0;
            for (int i = 1; i < daOrdinare.size(); i++) {
                if (daOrdinare.get(i).davantiA(daOrdinare.get(migliore))) {
                    migliore = i;
                }
            }
            classifica.add(daOrdinare.remove(migliore));
        }
        return classifica;
    }

    // ---------- overload: tutta la classifica o solo le prime n ----------
    static void stampaClassifica(ArrayList<Squadra> classifica, int quante) {
        for (int i = 0; i < quante && i < classifica.size(); i++) {
            System.out.println("  " + classifica.get(i).rigaClassifica(i + 1));
        }
    }

    static void stampaClassifica(ArrayList<Squadra> classifica) {
        stampaClassifica(classifica, classifica.size());
    }

    static void salvaClassifica(ArrayList<Squadra> classifica, String nomeFile) throws IOException {
        FileWriter w = new FileWriter(nomeFile);                // da capo: sovrascrive
        try {
            w.write("CLASSIFICA DEL TORNEO\n");
            for (int i = 0; i < classifica.size(); i++) {
                w.write(classifica.get(i).rigaClassifica(i + 1) + "\n");
            }
        } finally {
            w.close();
        }
    }

    public static void main(String[] args) {
        HashMap<String, Squadra> squadre = new HashMap<>();
        HashMap<String, Integer> frequenze = new HashMap<>();  // "1-1" -> quante volte
        LinkedList<Partita> pila = new LinkedList<>();          // l'ultima giocata sta in cima
        int valide = 0;

        File scarti = new File("scarti.txt");
        if (scarti.exists() && scarti.delete()) {
            System.out.println("Eliminato il vecchio scarti.txt");
        }

        try {
            for (String riga : leggiRighe("squadre.txt")) {
                Squadra s = creaSquadra(riga);
                squadre.put(s.nome, s);
            }

            ArrayList<String> righe = leggiRighe("risultati.txt");
            for (String riga : righe) {
                try {
                    Partita p = creaPartita(riga, squadre);
                    p.applica();
                    pila.push(p);
                    valide++;
                    String chiave = p.golCasa + "-" + p.golOspite;
                    frequenze.put(chiave, frequenze.getOrDefault(chiave, 0) + 1);
                } catch (NumberFormatException e) {
                    scarta(riga, "gol non numerici");
                } catch (IllegalArgumentException e) {
                    scarta(riga, e.getMessage());
                }
            }
            System.out.println("Partite valide: " + valide + " su " + righe.size());
        } catch (IOException e) {
            System.out.println("Impossibile leggere i dati: " + e.getMessage());
            return;
        }

        // chi non ha mai giocato esce dal torneo: prima le raccolgo, poi le tolgo
        ArrayList<String> daTogliere = new ArrayList<>();
        for (String nome : squadre.keySet()) {
            if (squadre.get(nome).giocate() == 0) {
                daTogliere.add(nome);
            }
        }
        for (String nome : daTogliere) {
            squadre.remove(nome);
            System.out.println(nome + " non ha giocato partite valide: esclusa");
        }

        int totaleGol = 0;
        for (Squadra s : squadre.values()) {
            totaleGol += s.golFatti;
        }
        System.out.println("Gol segnati in tutto: " + totaleGol);

        String piuFrequente = "";
        int volte = 0;
        for (Map.Entry<String, Integer> e : frequenze.entrySet()) {
            if (e.getValue() > volte) {
                piuFrequente = e.getKey();
                volte = e.getValue();
            }
        }
        System.out.println("Risultato più frequente: " + piuFrequente + " (" + volte + " volte)");

        System.out.println("Ultime 3 partite, dalla più recente:");
        for (int i = 0; i < 3; i++) {
            System.out.println("  " + pila.pop().risultato());
        }

        ArrayList<Squadra> classifica = ordina(new ArrayList<>(squadre.values()));
        System.out.println("Classifica:");
        stampaClassifica(classifica);
        System.out.println("In finale:");
        stampaClassifica(classifica, 2);

        try {
            salvaClassifica(classifica, "classifica.txt");
            System.out.println("Classifica salvata in classifica.txt");
        } catch (IOException e) {
            System.out.println("Salvataggio non riuscito: " + e.getMessage());
        }
    }
}

Prima della verifica

Lo schema che torna sempreGuarda i tre progetti: hanno tutti la stessa forma. Riconoscerla è metà del lavoro in una verifica.
  1. Classi: i sostantivi della consegna diventano classi e attributi, i verbi metodi; i metodi che non possono fare il loro lavoro lanciano un'eccezione.
  2. Lettura: File + exists, poi leggiRighe con FileReader e finally.
  3. Da riga a oggetto: split, length, parseInt, costruttore giusto; un try dentro il ciclo per saltare le righe sbagliate.
  4. Strutture: HashMap per trovare per nome o codice, ArrayList per l'ordine, LinkedList per coda o pila.
  5. Scrittura: FileWriter con true per un registro che cresce, senza per un file da riscrivere.
  6. Eccezioni: checked (IOException) dichiarate con throws e gestite nel main; unchecked lanciate con throw dai controlli; catch dal più specifico al più generale.
