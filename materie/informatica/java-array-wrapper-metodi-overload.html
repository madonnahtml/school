Java: array, wrapper, metodi e overload

Quattro strumenti che servono in qualsiasi programma Java: gli array per tenere tanti valori insieme, le wrapper classes per trasformare i numeri in oggetti, i metodi per dividere il programma in pezzi e l'overload per dare lo stesso nome a metodi che fanno la stessa cosa in modi diversi.

Che cos'è un array

In una frase Un array è una variabile che contiene più valori dello stesso tipo, messi in fila uno dopo l'altro. Ogni valore si raggiunge con il suo numero di posizione, l'indice.

Immagina di dover salvare i voti di uno studente. Senza array devi inventare una variabile per ogni voto; se i voti diventano trenta, servono trenta variabili e trenta righe per stamparli.

Senza array

int voto1 = 7;
int voto2 = 8;
int voto3 = 6;
int voto4 = 9;

Quattro variabili separate: per calcolare la media bisogna scriverle tutte a mano.

Con array

int[] voti = {7, 8, 6, 9};

Una sola variabile, voti, che contiene tutti i valori in ordine. Con un ciclo si scorrono tutti, che siano 4 o 400.

Un paragoneUn array è come una fila di armadietti della palestra: hanno tutti la stessa forma (stesso tipo), sono numerati e per aprirne uno basta conoscere il numero. Il numero degli armadietti si decide quando si costruisce la fila e non cambia più.
  • Tutti gli elementi sono dello stesso tipo: un int[] contiene solo int, un String[] solo stringhe.
  • La dimensione è fissa: si decide alla creazione e poi non si può allungare né accorciare. (Per liste che crescono si usa ArrayList, che vediamo con le wrapper.)
  • Le parentesi quadre [] dopo il tipo dicono "questo è un array di…": int[] si legge "array di interi".

Creare un array e usare gli indici

Ci sono due modi per creare un array.

1 · Con i valori già dentro

int[] numeri = {10, 20, 30, 40, 50};

Si usa quando i valori si conoscono già mentre si scrive il programma. La dimensione (5) la calcola Java contando i valori.

2 · Vuoto, con new

int[] numeri = new int[5];

Si usa quando i valori arriveranno dopo (dall'utente, da un calcolo…). Si dice solo quanti posti servono.

Un array creato con new non è davvero "vuoto": Java riempie ogni posto con un valore predefinito.

Gli indici partono da 0

In Java (come in C) il primo elemento ha indice 0. Quindi in un array di 5 elementi gli indici vanno da 0 a 4: l'ultimo indice è sempre lunghezza − 1.

Indice01234
Valore1020304050

Per leggere o modificare un elemento si scrive il nome dell'array e l'indice tra quadre:

System.out.println(numeri[0]);  // 10 (il primo)
System.out.println(numeri[4]);  // 50 (l'ultimo)

numeri[2] = 100;                // modifica: ora l'array è {10, 20, 100, 40, 50}
Errore classicoUsare un indice che non esiste, come numeri[5] in un array di 5 elementi, non dà errore quando compili, ma quando il programma gira si ferma con ArrayIndexOutOfBoundsException ("indice fuori dai limiti"). Succede quasi sempre per aver scritto <= invece di < in un ciclo.

length, for e foreach

Per lavorare con tutti gli elementi di un array si usano tre strumenti.

La proprietà length

int[] numeri = {10, 20, 30, 40, 50};
System.out.println(numeri.length);  // 5

length dice quanti elementi ha l'array. Si scrive senza parentesi perché è una proprietà (un dato), non un metodo.

Non confondereArray: numeri.length (senza parentesi). Stringa: nome.length() (con le parentesi, è un metodo). ArrayList: lista.size(). È un errore molto comune nelle verifiche.

Il ciclo for classico

for (int i = 0; i < numeri.length; i++) {
    numeri[i] = numeri[i] * 2;   // raddoppia ogni elemento
}
// ora numeri è {20, 40, 60, 80, 100}

La variabile i parte da 0 e arriva a length − 1: è proprio l'indice. Si usa quando serve sapere in che posizione si è, ad esempio per modificare gli elementi, per scorrere l'array al contrario o per guardare solo alcune posizioni.

Perché i < numeri.lengthScrivere numeri.length invece di 5 rende il ciclo giusto per qualsiasi dimensione: se domani l'array ha 7 elementi, il ciclo non va cambiato.

Il ciclo foreach (for "migliorato")

for (int numero : numeri) {
    System.out.println(numero);
}

Si legge: "per ogni numero in numeri". A ogni giro la variabile numero contiene un elemento, dal primo all'ultimo. È più corto e non si può sbagliare l'indice.

Il foreach non modifica l'arraynumero è una copia dell'elemento: scrivere numero = numero * 2; dentro il foreach cambia solo la copia, l'array resta uguale. Per modificare serve il for con l'indice.

Esempio guidato: somma, media e massimo

Mettiamo tutto insieme: un programma che, dato un array di numeri, calcola la somma, la media e trova il valore massimo.

public class Main {
    public static void main(String[] args) {
        int[] numeri = {10, 20, 15, 30, 25};
        int somma = 0;
        int massimo = numeri[0];          // parto dal primo elemento

        for (int numero : numeri) {
            somma += numero;              // somma = somma + numero
            if (numero > massimo) {
                massimo = numero;         // ho trovato un valore più grande
            }
        }

        double media = (double) somma / numeri.length;
        System.out.println("Somma: " + somma);      // 100
        System.out.println("Media: " + media);      // 20.0
        System.out.println("Massimo: " + massimo);  // 30
    }
}

Come funziona, passo per passo

  1. somma parte da 0: è l'"accumulatore", a ogni giro ci si aggiunge un numero.
  2. massimo parte dal primo elemento, non da 0: se tutti i numeri fossero negativi, partendo da 0 il risultato sarebbe sbagliato.
  3. Il foreach guarda un numero alla volta: lo aggiunge alla somma e, se è più grande del massimo trovato finora, lo prende come nuovo massimo.
  4. Alla fine si divide la somma per il numero di elementi.

Il cast (double) è fondamentaleIn Java intero diviso intero dà un intero: i decimali vengono buttati via. Con somma = 101 e 5 elementi, 101 / 5 vale 20, non 20.2. Scrivendo (double) somma / numeri.length trasformi la somma in decimale prima della divisione, e il risultato è 20.2.
Attenzione: (double) (somma / numeri.length) è sbagliato, perché fa prima la divisione intera e poi converte un numero già troncato.

Wrapper classes

Java ha due famiglie di tipi:

Tipi primitivi

int, double, boolean, char… Sono valori semplici: veloci, leggeri, ma non sono oggetti. Non hanno metodi e non possono valere null.

Una moneta in tasca.

Wrapper classes

Integer, Double, Boolean, Character… Sono classi che "avvolgono" (to wrap = incartare) un primitivo dentro un oggetto.

La stessa moneta, dentro una bustina con l'etichetta.

Perché servono

  • Le collezioni di Java, come ArrayList, possono contenere solo oggetti. Non si può scrivere ArrayList<int>: si scrive ArrayList<Integer>.
  • Le wrapper hanno metodi utili, per esempio per trasformare un testo in un numero.
  • Un oggetto può valere null, cioè "nessun valore", cosa impossibile per un primitivo.

Trucco per ricordarle: il nome della wrapper è il nome del primitivo con la maiuscola. Le due eccezioni sono int → Integer e char → Character.

Autoboxing e unboxing

Non serve convertire a mano: Java passa da primitivo a wrapper e viceversa da solo.

// Autoboxing: int → Integer (Java "mette nella scatola")
int n = 10;
Integer val = n;

// Unboxing: Integer → int (Java "toglie dalla scatola")
Integer v = 20;
int num = v;

È proprio l'autoboxing che permette di scrivere in modo naturale con un ArrayList:

import java.util.ArrayList;

ArrayList<Integer> voti = new ArrayList<>();
voti.add(8);              // autoboxing: l'int 8 diventa un Integer
voti.add(7);
int primo = voti.get(0);  // unboxing: l'Integer torna int
System.out.println(voti.size());  // 2

Metodi utili

int a = Integer.parseInt("25");          // 25     da testo a int
double b = Double.parseDouble("12.5");   // 12.5   da testo a double
String c = Integer.toString(100);        // "100"  da int a testo
int max = Integer.MAX_VALUE;             // 2147483647, il più grande int possibile

parseInt serve tantissimo: tutto quello che l'utente scrive (da tastiera, in un campo di un modulo, da un file) arriva come testo. Per farci dei calcoli bisogna prima trasformarlo in numero.

String testo = "7";
System.out.println(testo + 1);                    // "71"  (unisce due testi)
System.out.println(Integer.parseInt(testo) + 1);  // 8     (somma due numeri)
Attenzione
  • Integer.parseInt("ciao") o Integer.parseInt("12.5") fermano il programma con NumberFormatException: il testo deve essere un intero valido.
  • Se un Integer vale null, l'unboxing (int x = valoreNull;) causa una NullPointerException.
  • Per confrontare due Integer usa a.equals(b), non a == b: con gli oggetti == controlla se sono lo stesso oggetto, non se hanno lo stesso valore, e con numeri grandi dà false anche se i valori sono uguali.

I metodi

In una frase Un metodo è un blocco di codice con un nome che svolge un compito preciso. Lo si scrive una volta e lo si può chiamare (usare) tutte le volte che serve.

I metodi servono a non ripetere lo stesso codice, a organizzare il programma in pezzi piccoli e a renderlo più leggibile: calcolaMedia(voti) si capisce subito, dieci righe di cicli no. Il main stesso è un metodo: quello da cui parte il programma.

Un paragoneUn metodo è come una ricetta: ha un nome ("torta di mele"), degli ingredienti da ricevere (i parametri) e alla fine può consegnare qualcosa (il valore di ritorno). Chi la usa non deve sapere come è fatta dentro.

Com'è fatta l'intestazione

static int quadrato(int n) {
    return n * n;
}
static

Permette di chiamare il metodo direttamente dal main (che è anch'esso static), senza creare oggetti. Per ora mettilo sempre.

int

Il tipo di ritorno: che tipo di valore consegna il metodo. void se non consegna niente.

quadrato

Il nome: di solito un verbo, in camelCase (calcolaSomma, stampaArray).

(int n)

I parametri: i dati che il metodo riceve, ognuno con tipo e nome. Le parentesi vuote () se non ne riceve.

Metodi void e metodi con return

Metodo void

static void saluta() {
    System.out.println("Ciao!");
}

saluta();   // stampa: Ciao!

void = "vuoto": non restituisce nulla. Fa un'azione (stampa, modifica un array…) e basta.

Metodo con return

static int quadrato(int n) {
    return n * n;
}

int r = quadrato(5);   // r vale 25

Calcola un valore e lo restituisce a chi l'ha chiamato, che può salvarlo, stamparlo o usarlo in un altro calcolo.

  • Il valore dopo return deve essere del tipo dichiarato nell'intestazione.
  • return termina subito il metodo: le righe scritte dopo non vengono eseguite.
  • Un metodo con tipo di ritorno deve arrivare a un return in ogni caso, altrimenti il compilatore dà errore (missing return statement).
Errore classicoChiamare un metodo con return e "dimenticare" il risultato: quadrato(5); da solo calcola 25 e lo butta via. Bisogna usarlo: int r = quadrato(5); oppure System.out.println(quadrato(5));.

Parametri e argomenti

static void saluta(String nome) {      // nome è il PARAMETRO
    System.out.println("Ciao " + nome);
}

saluta("Marco");   // "Marco" è l'ARGOMENTO → stampa: Ciao Marco
saluta("Giulia");  // stampa: Ciao Giulia
ParametroArgomento
La variabile scritta nell'intestazione del metodo (String nome).Il valore concreto passato quando si chiama il metodo ("Marco").
È come la casella vuota di un modulo.È quello che ci scrivi dentro.

Gli argomenti devono essere tanti quanti i parametri, dello stesso tipo e nello stesso ordine. Con più parametri si separano con la virgola:

static double area(double base, double altezza) {
    return base * altezza / 2;
}

System.out.println(area(6, 4));   // 12.0

Metodi e array: un programma strutturato

Un programma ben scritto divide il lavoro in metodi, ognuno con un solo compito. Un metodo può ricevere un array come parametro e restituire un risultato calcolato su di esso.

public class Main {

    static int calcolaSomma(int[] n) {
        int s = 0;
        for (int x : n) s += x;
        return s;
    }

    static double calcolaMedia(int[] n) {
        return (double) calcolaSomma(n) / n.length;   // riusa calcolaSomma!
    }

    static int trovaMassimo(int[] n) {
        int max = n[0];
        for (int x : n) {
            if (x > max) max = x;
        }
        return max;
    }

    public static void main(String[] args) {
        int[] numeri = {10, 20, 30, 40};

        int somma = calcolaSomma(numeri);
        double media = calcolaMedia(numeri);

        System.out.println("Somma = " + somma);                  // 100
        System.out.println("Media = " + media);                  // 25.0
        System.out.println("Max = " + trovaMassimo(numeri));     // 40
    }
}
  • Il parametro si dichiara con le quadre: int[] n. Nella chiamata si passa solo il nome: calcolaSomma(numeri), senza quadre.
  • Dentro il metodo l'array si chiama n, fuori numeri: i nomi possono essere diversi, conta l'ordine.
  • calcolaMedia riusa calcolaSomma: non riscriviamo lo stesso ciclo due volte.
Ogni metodo fa una sola cosaCosì è più facile da leggere (il main sembra un elenco di passi), da controllare (se la media è sbagliata, guardo solo calcolaMedia) e da riusare in altri programmi.
Un array passato a un metodo può essere modificatoQuando passi un int a un metodo, il metodo riceve una copia del valore: se lo cambia, fuori non cambia niente. Con un array invece il metodo riceve il riferimento allo stesso array: se modifica n[0], cambia anche l'array del main. 
static void azzeraPrimo(int[] n) { n[0] = 0; }

int[] numeri = {10, 20, 30};
azzeraPrimo(numeri);
System.out.println(numeri[0]);   // 0

Overload dei metodi

In una frase L'overload (sovraccaricamento) è la possibilità di scrivere più metodi con lo stesso nome ma con parametri diversi. Quando lo chiami, Java sceglie da solo la versione giusta guardando gli argomenti che passi.

Senza overload dovremmo inventare nomi come sommaInteri, sommaDecimali, sommaTreNumeri… Con l'overload il nome è uno solo, somma, e chi usa il metodo non deve ricordarsi niente. Lo usi già senza saperlo: System.out.println ha una versione per int, una per double, una per String e così via.

Un paragoneIl verbo "aprire": si apre una porta, una bottiglia, un file. L'azione ha lo stesso nome, ma come si fa dipende da cosa ti danno in mano.

I parametri sono "diversi" se cambia almeno una di queste cose:

1 · Il tipo

static int somma(int a, int b) {
    return a + b;
}

static double somma(double a, double b) {
    return a + b;
}

somma(2, 3);       // usa la versione int    → 5
somma(2.5, 1.5);   // usa la versione double → 4.0

2 · Il numero

static int somma(int a, int b) {
    return a + b;
}

static int somma(int a, int b, int c) {
    return a + b + c;
}

somma(2, 3);      // 2 argomenti → 5
somma(2, 3, 4);   // 3 argomenti → 9

Conta anche l'ordine dei tipi: f(int a, String s) e f(String s, int a) sono due versioni diverse.

Cosa NON è overload

static int somma(int a, int b) { ... }
static double somma(int a, int b) { ... }   // ERRORE di compilazione
Cambiare solo il tipo di ritorno non bastaDavanti alla chiamata somma(2, 3), Java guarda solo il nome e gli argomenti: due int. Entrambe le versioni vanno bene e non c'è modo di scegliere, quindi il compilatore dà errore (method somma(int,int) is already defined). L'overload si basa sui parametri, non sul tipo restituito. Allo stesso modo, cambiare solo il nome dei parametri (somma(int x, int y)) non crea una nuova versione.
Cosa cambia tra le due versioniÈ overload?
Tipo dei parametri: (int, int) e (double, double)Sì
Numero dei parametri: (int, int) e (int, int, int)Sì
Ordine dei tipi: (int, String) e (String, int)Sì
Solo il tipo di ritornoNo, errore
Solo il nome dei parametriNo, errore

Mappa riassuntiva

  • Array = più valori dello stesso tipo in una variabile; dimensione fissa. Si crea con {…} o con new int[n] (valori iniziali a 0).
  • Indici da 0 a length − 1; fuori da lì → ArrayIndexOutOfBoundsException.
  • length senza parentesi. for con indice per modificare; foreach per leggere tutto.
  • Media: (double) somma / n.length, altrimenti la divisione è intera.
  • Wrapper = oggetti che avvolgono i primitivi (Integer, Double, Boolean, Character…). Servono per ArrayList e per metodi come Integer.parseInt.
  • Autoboxing primitivo → wrapper, unboxing wrapper → primitivo: automatici.
  • Metodo = blocco con nome e un compito. void fa un'azione; con tipo di ritorno usa return per consegnare un valore.
  • Parametro = variabile nell'intestazione; argomento = valore passato nella chiamata.
  • Overload = stesso nome, parametri diversi (tipo, numero, ordine). Il solo tipo di ritorno non basta.

Esercizi

01Cosa stampa? facile
int[] a = new int[4];
a[1] = 5;
a[3] = a[1] * 2;
System.out.println(a.length);
System.out.println(a[0] + a[1] + a[3]);
System.out.println(a[a.length - 1]);
Soluzione

4, poi 15, poi 10. L'array dopo le assegnazioni è {0, 5, 0, 10}: a[0] vale 0 perché un array di int creato con new parte tutto a zero. a[a.length - 1] è il modo sicuro per prendere l'ultimo elemento.

02Trova l'errore facile
int[] voti = {6, 7, 8};
for (int i = 0; i <= voti.length; i++) {
    System.out.println(voti[i]);
}
Soluzione

Con <= l'ultimo giro ha i = 3, ma gli indici validi sono 0, 1, 2: il programma stampa 6, 7, 8 e poi si ferma con ArrayIndexOutOfBoundsException. La condizione giusta è i < voti.length. In alternativa, visto che si legge soltanto, un foreach: for (int v : voti) System.out.println(v);

03Contare i promossi medio

Scrivi un metodo contaSufficienti(int[] voti) che restituisce quanti voti sono maggiori o uguali a 6. Provalo nel main con l'array {4, 6, 7, 5, 9, 6}.

Soluzione
static int contaSufficienti(int[] voti) {
    int conta = 0;
    for (int v : voti) {
        if (v >= 6) conta++;
    }
    return conta;
}

public static void main(String[] args) {
    int[] voti = {4, 6, 7, 5, 9, 6};
    System.out.println(contaSufficienti(voti));   // 4
}

È lo stesso schema della somma: un contatore che parte da 0 e cresce di 1 solo quando la condizione è vera. Il metodo restituisce un numero intero, quindi il tipo di ritorno è int.

04Raddoppiare un array medio

Scrivi un metodo void raddoppia(int[] n) che moltiplica per 2 ogni elemento dell'array, e un metodo void stampa(int[] n) che lo stampa su una riga. Perché in raddoppia non si può usare il foreach?

Soluzione
static void raddoppia(int[] n) {
    for (int i = 0; i < n.length; i++) {
        n[i] = n[i] * 2;
    }
}

static void stampa(int[] n) {
    for (int x : n) System.out.print(x + " ");
    System.out.println();
}

public static void main(String[] args) {
    int[] numeri = {1, 2, 3};
    raddoppia(numeri);
    stampa(numeri);   // 2 4 6
}

Nel foreach la variabile contiene una copia dell'elemento: cambiarla non cambia l'array. Serve l'indice i per scrivere in n[i]. I metodi sono void perché non devono restituire niente: raddoppia modifica direttamente l'array del main, perché riceve il riferimento allo stesso array.

05Da testo a numero medio

Hai l'array String[] dati = {"12", "7", "30"}; (per esempio letto da un file). Calcola la somma dei numeri. Poi spiega cosa stampano dati[0] + dati[1] e perché.

Soluzione
String[] dati = {"12", "7", "30"};
int somma = 0;
for (String d : dati) {
    somma += Integer.parseInt(d);
}
System.out.println(somma);              // 49
System.out.println(dati[0] + dati[1]);  // 127

Gli elementi sono stringhe: con + due stringhe vengono attaccate, quindi "12" + "7" dà "127". Per sommare i valori bisogna prima trasformarli con Integer.parseInt.

06Overload: quale versione viene usata? ragionamento
static void info(int x)            { System.out.println("intero"); }
static void info(double x)         { System.out.println("decimale"); }
static void info(String s)         { System.out.println("testo"); }
static void info(int x, int y)     { System.out.println("due interi"); }

Cosa stampano info(5), info(5.0), info("5"), info(5, 6)? E se aggiungessi static int info(int x) { return x; }?

Soluzione

intero, decimale, testo, due interi: Java sceglie guardando tipo e numero degli argomenti. 5 senza punto è un int, 5.0 è un double, "5" tra virgolette è una String.

Aggiungere static int info(int x) è un errore: ha gli stessi parametri di void info(int x) e cambia solo il tipo di ritorno, che non basta per l'overload.

07Il metodo massimo, in tre versioni ragionamento

Scrivi tre metodi tutti chiamati massimo: uno che riceve due int, uno che ne riceve tre e uno che riceve un array di int. Cerca di riusare il primo dentro gli altri.

Soluzione
static int massimo(int a, int b) {
    if (a > b) return a;
    return b;
}

static int massimo(int a, int b, int c) {
    return massimo(massimo(a, b), c);
}

static int massimo(int[] n) {
    int max = n[0];
    for (int x : n) max = massimo(max, x);
    return max;
}

public static void main(String[] args) {
    System.out.println(massimo(3, 8));            // 8
    System.out.println(massimo(3, 8, 5));         // 8
    System.out.println(massimo(new int[]{4, 9, 2})); // 9
}

Sono tre overload perché cambiano numero o tipo dei parametri. La versione a tre parametri e quella con l'array chiamano quella a due: la logica del confronto è scritta una volta sola. new int[]{4, 9, 2} crea un array "al volo" da passare come argomento.
