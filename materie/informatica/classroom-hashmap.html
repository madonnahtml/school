Classroom: HashMap

L'esercitazione sulle HashMap assegnata su Google Classroom: tre esercizi guidati (rubrica, inventario, registro voti) e una sfida finale, una biblioteca con menu. Qui trovi la consegna riportata fedelmente, la risposta e la spiegazione di ogni passo. La teoria è nel capitolo Java: HashMap.

Come usare questa paginaLeggi la consegna (è quella del PDF del professore), prova a scrivere il programma da solo e solo dopo apri la risposta spiegata. Ogni programma è stato compilato ed eseguito con Java 21: l'output che vedi è quello vero.
Attenzione all'ordineUna HashMap non tiene le coppie nell'ordine in cui le hai inserite. Quando un programma stampa la mappa intera, le righe qui sotto sono quelle uscite davvero sul nostro computer, ma sul tuo l'ordine può essere diverso: conta che ci siano tutte le coppie, non la loro posizione. Più dettagli in Esercizi: HashMap e in Come funziona dentro.

Esercizio 1 – Rubrica telefonica

Ripasso lampoput(k, v) aggiunge una coppia, oppure sostituisce il valore se la chiave c'è già; get(k) legge, containsKey(k) controlla, remove(k) toglie, size() conta le coppie. Teoria: Aggiungere e modificare con put(), Leggere con get() e controllare, Rimuovere, svuotare e contare.
01Rubrica telefonica facile

Consegna. Crea un programma Java che utilizzi una:

HashMap<String, String>

per rappresentare una rubrica telefonica.

Inserisci:

"Marco" → "3331234567"
"Luca"  → "3477654321"
"Anna"  → "3201112233"

Poi:

  1. stampa tutta la rubrica;
  2. stampa il numero di Marco;
  3. verifica se "Anna" è presente;
  4. modifica il numero di Luca;
  5. elimina Marco;
  6. stampa il numero di contatti rimasti.
Risposta spiegata

Ragionamento

  1. Cerco per nome, quindi il nome è la chiave e il numero è il valore. Il numero è una String e non un int: non ci devo fare calcoli, e 3331234567 non ci starebbe neanche in un int (il massimo è circa 2,1 miliardi).
  2. Per stampare tutta la rubrica basta System.out.println(rubrica): Java scrive la mappa nella forma {chiave=valore, ...}.
  3. "Verifica se Anna è presente" è un lavoro per containsKey, che risponde true/false.
  4. "Modifica il numero di Luca": non esiste un metodo "modifica", si usa ancora put. La chiave "Luca" c'è già, quindi il vecchio numero viene sostituito. Il nuovo numero non è dato dal PDF: ne ho scelto uno io.
  5. Per eliminare uso remove("Marco"), per contare size().

Codice

import java.util.HashMap;

public class Rubrica {
    public static void main(String[] args) {
        // nome -> numero di telefono
        HashMap<String, String> rubrica = new HashMap<>();
        rubrica.put("Marco", "3331234567");
        rubrica.put("Luca", "3477654321");
        rubrica.put("Anna", "3201112233");

        // 1. stampa tutta la rubrica
        System.out.println("Rubrica: " + rubrica);

        // 2. stampa il numero di Marco
        System.out.println("Numero di Marco: " + rubrica.get("Marco"));

        // 3. verifica se "Anna" è presente
        if (rubrica.containsKey("Anna")) {
            System.out.println("Anna è presente in rubrica");
        } else {
            System.out.println("Anna non è in rubrica");
        }

        // 4. modifica il numero di Luca (put su una chiave che esiste già = sostituisce)
        rubrica.put("Luca", "3489998877");
        System.out.println("Nuovo numero di Luca: " + rubrica.get("Luca"));

        // 5. elimina Marco
        rubrica.remove("Marco");
        System.out.println("Marco eliminato. Rubrica: " + rubrica);

        // 6. stampa il numero di contatti rimasti
        System.out.println("Contatti rimasti: " + rubrica.size());
    }
}

Output

Rubrica: {Marco=3331234567, Luca=3477654321, Anna=3201112233}
Numero di Marco: 3331234567
Anna è presente in rubrica
Nuovo numero di Luca: 3489998877
Marco eliminato. Rubrica: {Luca=3489998877, Anna=3201112233}
Contatti rimasti: 2

Perché funziona

  • Dopo il put("Luca", "3489998877") le coppie sono ancora 3, non 4: una chiave non può comparire due volte, quindi il put ha cambiato il valore invece di aggiungere una riga.
  • Dopo il remove restano Luca e Anna, quindi size() vale 2.
  • L'ordine delle coppie stampate (qui Marco, Luca, Anna) è quello uscito sul nostro computer: non è garantito.

Errori da evitare

  • rubrica.get("marco") con la minuscola dà null: le chiavi String distinguono maiuscole e minuscole.
  • Usare containsValue("Anna") per il punto 3: cercherebbe "Anna" tra i numeri e risponderebbe false.

Esercizio 2 – Inventario

Ripasso lampoPer aumentare un valore numerico si legge il vecchio valore con get, si somma e si rimette con put: m.put(k, m.get(k) + 2). Teoria: Aggiungere e modificare con put().
02Inventario facile

Consegna. Crea una HashMap per rappresentare un piccolo inventario:

HashMap<String, Integer>

Dove:

prodotto → quantità

Inserisci:

"Mouse" → 10
"Tastiera" → 5
"Monitor" → 3

Poi il programma deve:

  • stampare l'inventario;
  • mostrare quanti Mouse sono disponibili;
  • aggiungere 2 Mouse;
  • eliminare il Monitor;
  • stampare il numero di prodotti rimasti.

Suggerimento: per aggiungere 2 Mouse puoi fare:

int quantita = inventario.get("Mouse");

inventario.put("Mouse", quantita + 2);
Risposta spiegata

Ragionamento

  1. Il valore è una quantità, un numero intero: tra < > va la classe Integer, non int.
  2. "Aggiungere 2 Mouse" non vuol dire put("Mouse", 2): quello metterebbe 2 al posto di 10. Si segue il suggerimento: leggo 10 con get, sommo 2, rimetto 12 con put.
  3. int quantita = inventario.get("Mouse"); funziona perché Java trasforma da solo l'Integer restituito in int (unboxing).
  4. Monitor si toglie con remove, i prodotti rimasti si contano con size().

Codice

import java.util.HashMap;

public class Inventario {
    public static void main(String[] args) {
        // prodotto -> quantità
        HashMap<String, Integer> inventario = new HashMap<>();
        inventario.put("Mouse", 10);
        inventario.put("Tastiera", 5);
        inventario.put("Monitor", 3);

        // stampare l'inventario
        System.out.println("Inventario: " + inventario);

        // mostrare quanti Mouse sono disponibili
        System.out.println("Mouse disponibili: " + inventario.get("Mouse"));

        // aggiungere 2 Mouse (come nel suggerimento: leggo, sommo, rimetto)
        int quantita = inventario.get("Mouse");
        inventario.put("Mouse", quantita + 2);
        System.out.println("Dopo l'arrivo di 2 Mouse: " + inventario.get("Mouse"));

        // eliminare il Monitor
        inventario.remove("Monitor");
        System.out.println("Monitor eliminato. Inventario: " + inventario);

        // stampare il numero di prodotti rimasti
        System.out.println("Prodotti rimasti: " + inventario.size());
    }
}

Output

Inventario: {Monitor=3, Mouse=10, Tastiera=5}
Mouse disponibili: 10
Dopo l'arrivo di 2 Mouse: 12
Monitor eliminato. Inventario: {Mouse=12, Tastiera=5}
Prodotti rimasti: 2

Qui si vede bene che l'ordine non è quello di inserimento: abbiamo messo Mouse, Tastiera, Monitor e la stampa comincia da Monitor.

Errori da evitare

  • "Prodotti rimasti" è 2, non 15. size() conta le coppie (i tipi di prodotto: Mouse e Tastiera), non i pezzi in magazzino (12 + 5). Per sommare i pezzi servirebbe scorrere i valori con values().
  • Il suggerimento funziona solo se la chiave esiste: inventario.get("Webcam") darebbe null, e mettere null in un int provoca una NullPointerException. Con un prodotto che potrebbe mancare, prima si controlla con containsKey (oppure si usa getOrDefault(k, 0)).

Esercizio 3 – Registro voti

Ripasso lampoclear() svuota la mappa in un colpo solo: dopo, size() vale 0 e la stampa è {}. Teoria: Rimuovere, svuotare e contare.
03Registro voti facile

Consegna. Realizza un programma che utilizzi:

HashMap<String, Double>

per memorizzare il voto di alcuni studenti.

Esempio:

Mario → 7.5
Lucia → 8.0
Paolo → 6.5

Il programma deve:

  1. creare la HashMap;
  2. inserire gli studenti;
  3. stampare il voto di Lucia;
  4. modificare il voto di Paolo portandolo a 7.0;
  5. verificare se esiste uno studente chiamato "Mario";
  6. eliminare Lucia;
  7. stampare quanti studenti sono rimasti;
  8. infine svuotare completamente la HashMap.
Risposta spiegata

Ragionamento

  1. I voti hanno la virgola, quindi il valore è Double (la classe di double).
  2. Seguo gli 8 punti nell'ordine, uno per riga di codice: è lo stesso schema degli esercizi 1 e 2 con in più clear().
  3. "Portare il voto di Paolo a 7.0" è di nuovo un put su una chiave già presente.
  4. "Verificare se esiste Mario" è containsKey("Mario"): stampo direttamente il boolean.
  5. Dopo clear() stampo la mappa e size() per far vedere che è davvero vuota.

Codice

import java.util.HashMap;

public class RegistroVoti {
    public static void main(String[] args) {
        // 1. creare la HashMap: studente -> voto
        HashMap<String, Double> voti = new HashMap<>();

        // 2. inserire gli studenti
        voti.put("Mario", 7.5);
        voti.put("Lucia", 8.0);
        voti.put("Paolo", 6.5);
        System.out.println("Registro: " + voti);

        // 3. stampare il voto di Lucia
        System.out.println("Voto di Lucia: " + voti.get("Lucia"));

        // 4. modificare il voto di Paolo portandolo a 7.0
        voti.put("Paolo", 7.0);
        System.out.println("Nuovo voto di Paolo: " + voti.get("Paolo"));

        // 5. verificare se esiste uno studente chiamato "Mario"
        System.out.println("Esiste Mario? " + voti.containsKey("Mario"));

        // 6. eliminare Lucia
        voti.remove("Lucia");
        System.out.println("Lucia eliminata. Registro: " + voti);

        // 7. stampare quanti studenti sono rimasti
        System.out.println("Studenti rimasti: " + voti.size());

        // 8. svuotare completamente la HashMap
        voti.clear();
        System.out.println("Dopo clear(): " + voti + ", studenti: " + voti.size());
    }
}

Output

Registro: {Paolo=6.5, Lucia=8.0, Mario=7.5}
Voto di Lucia: 8.0
Nuovo voto di Paolo: 7.0
Esiste Mario? true
Lucia eliminata. Registro: {Paolo=7.0, Mario=7.5}
Studenti rimasti: 2
Dopo clear(): {}, studenti: 0

Perché funziona

  • voti.put("Mario", 7.5) compila anche se il valore è un Double: Java "impacchetta" da solo il double 7.5 (autoboxing). Attenzione però: voti.put("Paolo", 7) non compila, perché 7 è un int e Java non lo converte in Double. Per questo si scrive 7.0, come chiede la consegna.
  • Un Double stampato mostra sempre la parte decimale: 8.0, non 8.
  • clear() svuota la mappa ma la mappa esiste ancora: si può riempire di nuovo con put. È diverso da voti = null, che butterebbe via la mappa.

Sfida finale

Ripasso lampoUn programma a menu è un ciclo do ... while che stampa le voci, legge la scelta con Scanner e la smista con uno switch, finché l'utente non sceglie di uscire. Per le HashMap, il riepilogo di tutti i metodi è in Mappa riassuntiva.
04La biblioteca completo

Consegna. Scrivi un programma per una biblioteca utilizzando:

HashMap<String, Integer>

dove:

titolo del libro → numero di copie

Inserisci almeno 4 libri.

Il programma deve permettere di:

1. Visualizzare tutti i libri
2. Cercare un libro
3. Aggiungere un libro
4. Modificare il numero di copie
5. Eliminare un libro
6. Visualizzare quanti libri sono presenti
7. Svuotare la biblioteca

Per questa sfida prova a utilizzare soltanto i metodi che abbiamo visto:

put()
get()
containsKey()
containsValue()
remove()
size()
clear()
Risposta spiegata

Ragionamento

  1. La struttura. La consegna elenca 7 azioni da fare "a richiesta": è un programma a menu. Un ciclo do ... while stampa il menu, legge la scelta e la passa a uno switch con un case per voce. Aggiungo la voce 0. Esci, altrimenti il programma non finirebbe mai.
  2. I dati di partenza. Prima del ciclo metto 4 libri con put, come chiesto.
  3. Leggere l'input. I titoli hanno spazi ("I promessi sposi"), quindi li leggo con nextLine(). Anche i numeri li leggo come riga e li converto con Integer.parseInt: così non c'è il classico problema di nextInt() che lascia l'"a capo" nel buffer e fa saltare il nextLine() successivo. Il metodo leggiNumero ripete la domanda se l'utente non scrive un numero (try/catch su NumberFormatException).
  4. Voce per voce, con i soli metodi permessi:
    VoceMetodi usatiIdea
    1. Visualizzare tuttisize, containsValue + stampa della mappase è vuota lo dico; altrimenti stampo la mappa e avviso se c'è un libro con 0 copie
    2. CercarecontainsKey, getse il titolo c'è stampo le copie, se no un messaggio
    3. AggiungerecontainsKey, putse il titolo c'è già non faccio put: sostituirebbe le copie
    4. ModificarecontainsKey, get, putsolo se il titolo esiste; put su chiave esistente = sostituisce
    5. EliminarecontainsKey, removecontrollo prima, così posso dire "non c'è"
    6. Quanti librisizenumero di titoli diversi
    7. Svuotareclearchiedo conferma: è un'operazione che non si può annullare
  5. Gli errori gestiti. Titolo non trovato (cerca, modifica, elimina), titolo già presente (aggiungi), numero di copie negativo, scelta che non esiste nel menu (default), testo al posto di un numero.

Codice

import java.util.HashMap;
import java.util.Scanner;

public class Biblioteca {

    // Legge un numero intero; se l'utente scrive altro, lo richiede
    static int leggiNumero(Scanner sc, String messaggio) {
        while (true) {
            System.out.print(messaggio);
            String riga = sc.nextLine();
            try {
                return Integer.parseInt(riga.trim());
            } catch (NumberFormatException e) {
                System.out.println("Devi scrivere un numero intero.");
            }
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        // titolo del libro -> numero di copie
        HashMap<String, Integer> biblioteca = new HashMap<>();
        biblioteca.put("I promessi sposi", 3);
        biblioteca.put("Il piccolo principe", 5);
        biblioteca.put("Pinocchio", 2);
        biblioteca.put("1984", 4);

        int scelta;
        do {
            System.out.println();
            System.out.println("===== BIBLIOTECA =====");
            System.out.println("1. Visualizzare tutti i libri");
            System.out.println("2. Cercare un libro");
            System.out.println("3. Aggiungere un libro");
            System.out.println("4. Modificare il numero di copie");
            System.out.println("5. Eliminare un libro");
            System.out.println("6. Visualizzare quanti libri sono presenti");
            System.out.println("7. Svuotare la biblioteca");
            System.out.println("0. Esci");
            scelta = leggiNumero(sc, "Scelta: ");

            String titolo;
            int copie;
            switch (scelta) {
                case 1:
                    if (biblioteca.size() == 0) {
                        System.out.println("La biblioteca è vuota.");
                    } else {
                        // stampa della mappa intera: {titolo=copie, ...}
                        System.out.println("Libri (titolo=copie): " + biblioteca);
                        if (biblioteca.containsValue(0)) {
                            System.out.println("Attenzione: c'è almeno un libro con 0 copie.");
                        }
                    }
                    break;

                case 2:
                    System.out.print("Titolo da cercare: ");
                    titolo = sc.nextLine();
                    if (biblioteca.containsKey(titolo)) {
                        System.out.println("\"" + titolo + "\" c'è: " + biblioteca.get(titolo) + " copie.");
                    } else {
                        System.out.println("\"" + titolo + "\" non è in biblioteca.");
                    }
                    break;

                case 3:
                    System.out.print("Titolo del nuovo libro: ");
                    titolo = sc.nextLine();
                    if (biblioteca.containsKey(titolo)) {
                        // put sostituirebbe le copie: meglio avvisare
                        System.out.println("\"" + titolo + "\" c'è già: usa la voce 4 per cambiare le copie.");
                    } else {
                        copie = leggiNumero(sc, "Numero di copie: ");
                        if (copie < 0) {
                            System.out.println("Il numero di copie non può essere negativo.");
                        } else {
                            biblioteca.put(titolo, copie);
                            System.out.println("Aggiunto \"" + titolo + "\" con " + copie + " copie.");
                        }
                    }
                    break;

                case 4:
                    System.out.print("Titolo da modificare: ");
                    titolo = sc.nextLine();
                    if (biblioteca.containsKey(titolo)) {
                        System.out.println("Copie attuali: " + biblioteca.get(titolo));
                        copie = leggiNumero(sc, "Nuovo numero di copie: ");
                        if (copie < 0) {
                            System.out.println("Il numero di copie non può essere negativo.");
                        } else {
                            biblioteca.put(titolo, copie);   // chiave esistente: sostituisce
                            System.out.println("Ora \"" + titolo + "\" ha " + copie + " copie.");
                        }
                    } else {
                        System.out.println("\"" + titolo + "\" non è in biblioteca.");
                    }
                    break;

                case 5:
                    System.out.print("Titolo da eliminare: ");
                    titolo = sc.nextLine();
                    if (biblioteca.containsKey(titolo)) {
                        biblioteca.remove(titolo);
                        System.out.println("\"" + titolo + "\" eliminato.");
                    } else {
                        System.out.println("\"" + titolo + "\" non è in biblioteca.");
                    }
                    break;

                case 6:
                    System.out.println("Titoli presenti: " + biblioteca.size());
                    break;

                case 7:
                    System.out.print("Vuoi davvero svuotare la biblioteca? (s/n): ");
                    String risposta = sc.nextLine();
                    if (risposta.equals("s")) {
                        biblioteca.clear();
                        System.out.println("Biblioteca svuotata.");
                    } else {
                        System.out.println("Operazione annullata.");
                    }
                    break;

                case 0:
                    System.out.println("Arrivederci!");
                    break;

                default:
                    System.out.println("Scelta non valida.");
            }
        } while (scelta != 0);

        sc.close();
    }
}

Come si "visualizzano tutti i libri" con quei 7 metodi

Il punto delicato della sfida è la voce 1. Nell'elenco dei metodi permessi non c'è nessun modo per scorrere la mappa: keySet(), values() ed entrySet() (vedi Scorrere una HashMap) non ci sono, e una mappa non ha indici, quindi niente for (int i = 0; ...) con get(i). Ci sono due strade:

import java.util.HashMap;

public class ElencoLibri {
    public static void main(String[] args) {
        HashMap<String, Integer> biblioteca = new HashMap<>();
        biblioteca.put("I promessi sposi", 3);
        biblioteca.put("Il piccolo principe", 5);
        biblioteca.put("Pinocchio", 2);
        biblioteca.put("1984", 4);

        // Modo A: stampa della mappa (usa toString, che Java chiama da solo)
        System.out.println(biblioteca);

        // Modo B: for-each sulle chiavi + get (keySet non è nell'elenco della sfida)
        for (String titolo : biblioteca.keySet()) {
            System.out.println("- " + titolo + ": " + biblioteca.get(titolo) + " copie");
        }
    }
}
{Pinocchio=2, 1984=4, I promessi sposi=3, Il piccolo principe=5}
- Pinocchio: 2 copie
- 1984: 4 copie
- I promessi sposi: 3 copie
- Il piccolo principe: 5 copie
  • Modo A, stampa della mappa (quello scelto nel programma). System.out.println(biblioteca) non usa nessun metodo fuori dall'elenco scritto da noi: è Java che, per trasformare la mappa in testo, chiama da solo toString(). Risultato: tutte le coppie in una riga, {titolo=copie, ...}.
  • Modo B, for-each su keySet() con get per ogni titolo. L'elenco viene più bello (una riga per libro, con il testo che vogliamo), ma usa keySet(), che la consegna non mette tra i metodi visti.

Scelta motivata: nel programma usiamo il modo A perché la consegna chiede di provare a usare soltanto quei sette metodi, e la stampa della mappa li rispetta mostrando comunque tutti i titoli con le loro copie. Il modo B è la versione "da programma vero": se il professore lo permette, basta sostituire nel case 1 la riga della stampa con il for. In tutti e due i casi l'ordine dei libri non è garantito (si vede anche nella sessione: Pinocchio esce per primo).

Perché funziona

  • containsKey prima di tutto. In cerca, modifica ed elimina il controllo serve a dare un messaggio chiaro invece di stampare null. In "aggiungi" serve a non distruggere i dati: un put su un titolo esistente avrebbe cambiato le copie di Pinocchio da 2 al nuovo numero, senza avvisare.
  • containsValue(0) è il modo naturale di usare il settimo metodo: risponde alla domanda "c'è almeno un libro esaurito?" senza dover scorrere la mappa. Nella sessione, dopo aver messo a 0 le copie del Piccolo principe, l'avviso compare.
  • "Quanti libri sono presenti" l'abbiamo letto come numero di titoli, cioè size(). Il numero totale di copie (2 + 2 + 3 + 0) richiederebbe di sommare tutti i valori, e quindi values(), che non è nell'elenco.
  • Voce 7 con conferma: dopo clear() la voce 1 dice "La biblioteca è vuota" e la voce 6 dice 0: la mappa esiste ancora ed è pronta per nuovi put.
  • Dopo aver eliminato "1984", il secondo tentativo dà "non è in biblioteca": la chiave non c'è più.

Errori da evitare

  • Leggere la scelta con nextInt() e il titolo con nextLine(): il titolo risulterebbe vuoto, perché nextLine() legge l'"a capo" rimasto dopo il numero.
  • Confrontare la risposta della conferma con == (risposta == "s"): con le String si usa equals.
  • Dimenticare break in un case: lo switch proseguirebbe nel case successivo.
