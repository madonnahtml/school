Come usare questa paginaLeggi la consegna, prova a scrivere il programma da solo (su carta o al computer) e solo dopo apri la soluzione spiegata. Gli esercizi vanno dal più facile al più difficile; l'ultimo li mette insieme tutti. Ogni programma è stato compilato ed eseguito: l'output che vedi è quello vero.

Array: creare, leggere e scorrere

Ripasso lampoUn array ha una lunghezza fissa decisa alla creazione. Gli indici vanno da 0 a length - 1. Si scorre con il for classico (quando serve l'indice) o con il foreach (quando servono solo i valori). Teoria: Che cos'è un array.
01Le temperature della settimana facile

Consegna. Crea un array di double con le temperature di 7 giorni: 12.5, 14.0, 9.5, 16.0, 13.5, 11.0, 15.5. Il programma deve stampare quanti giorni ci sono, la temperatura del primo e dell'ultimo giorno e poi tutte le temperature numerate da 1 a 7.

Vincolo: per l'ultimo giorno non scrivere temp[6]: il programma deve funzionare anche se aggiungi altri giorni.

Output atteso:

Giorni registrati: 7
Primo giorno: 12.5
Ultimo giorno: 15.5
Giorno 1: 12.5 gradi
Giorno 2: 14.0 gradi
Giorno 3: 9.5 gradi
Giorno 4: 16.0 gradi
Giorno 5: 13.5 gradi
Giorno 6: 11.0 gradi
Giorno 7: 15.5 gradi
Soluzione spiegata

Ragionamento

  1. I valori sono già noti, quindi uso l'inizializzazione diretta con le graffe: Java conta da solo gli elementi.
  2. Il numero di giorni è temp.length (7). È una proprietà, quindi senza parentesi.
  3. Il primo elemento è sempre all'indice 0. L'ultimo è a length - 1: con 7 elementi gli indici vanno da 0 a 6.
  4. Per numerare i giorni da 1 serve l'indice, quindi uso il for classico e stampo i + 1.

Codice

public class Temperature {
    public static void main(String[] args) {
        double[] temp = {12.5, 14.0, 9.5, 16.0, 13.5, 11.0, 15.5};

        System.out.println("Giorni registrati: " + temp.length);
        System.out.println("Primo giorno: " + temp[0]);
        System.out.println("Ultimo giorno: " + temp[temp.length - 1]);

        for (int i = 0; i < temp.length; i++) {
            System.out.println("Giorno " + (i + 1) + ": " + temp[i] + " gradi");
        }
    }
}

Perché funziona

  • temp[temp.length - 1] si adatta da solo: se l'array avesse 30 elementi indicherebbe il 30°.
  • (i + 1) è tra parentesi: senza, Java farebbe prima "Giorno " + i (testo) e poi attaccherebbe 1, stampando "Giorno 01", "Giorno 11"…
  • La condizione è i < temp.length e non <=: con <= l'ultimo giro userebbe temp[7], che non esiste (ArrayIndexOutOfBoundsException).
02Cosa contiene l'array? facile

Consegna. Senza eseguirlo, scrivi su carta cosa stampa questo frammento. Poi spiega perché alcune caselle valgono 0.

int[] v = new int[5];
v[0] = 4;
v[2] = v[0] * 3;
v[4] = v[2] - v[0];
v[1] = v.length;
for (int x : v) {
    System.out.print(x + " ");
}
Soluzione spiegata

Ragionamento: la tabella delle caselle

Il modo più sicuro è disegnare l'array e aggiornarlo riga per riga.

Istruzione[0][1][2][3][4]
new int[5]00000
v[0] = 440000
v[2] = v[0] * 3401200
v[4] = v[2] - v[0]401208
v[1] = v.length451208

Output

4 5 12 0 8

Perché alcune caselle valgono 0

Con new int[5] Java crea 5 caselle e le riempie con il valore di default: 0 per gli int (0.0 per i double, false per i boolean, null per le String). La casella [3] non viene mai assegnata, quindi resta 0. Nota che v.length vale 5 anche se alcune caselle sono "vuote": la lunghezza è il numero di caselle, non il numero di valori inseriti.

03Sufficienti e insufficienti facile

Consegna. Dato l'array int[] voti = {6, 4, 8, 5, 9, 7, 3, 6}; conta quanti voti sono sufficienti (6 o più) e quanti insufficienti. Poi stampa le posizioni (gli indici) dei voti insufficienti.

Usa un foreach per contare e un for classico per le posizioni, e spiega perché.

Output atteso:

Sufficienti: 5
Insufficienti: 3
Posizioni delle insufficienze: 1 3 6
Soluzione spiegata

Ragionamento

  1. Per contare servono due contatori che partono da 0 e aumentano di 1 (++) ogni volta che la condizione è vera.
  2. Per contare mi basta il valore di ogni voto, non la sua posizione: il foreach è perfetto, più corto e senza rischio di sbagliare l'indice.
  3. Per stampare le posizioni invece mi serve l'indice i: il foreach non lo dà, quindi uso il for classico.

Codice

public class Voti {
    public static void main(String[] args) {
        int[] voti = {6, 4, 8, 5, 9, 7, 3, 6};

        int sufficienti = 0;
        int insufficienti = 0;
        for (int v : voti) {
            if (v >= 6) {
                sufficienti++;
            } else {
                insufficienti++;
            }
        }

        System.out.println("Sufficienti: " + sufficienti);
        System.out.println("Insufficienti: " + insufficienti);

        System.out.print("Posizioni delle insufficienze: ");
        for (int i = 0; i < voti.length; i++) {
            if (voti[i] < 6) {
                System.out.print(i + " ");
            }
        }
        System.out.println();
    }
}

Da ricordare

  • Regola pratica: foreach quando leggi solo i valori; for classico quando ti serve la posizione o quando devi modificare l'array.
  • I contatori vanno dichiarati prima del ciclo. Se li dichiari dentro, ripartono da 0 a ogni giro.
  • Si poteva anche calcolare insufficienti = voti.length - sufficienti senza il secondo contatore: è un buon controllo per vedere se i conti tornano (5 + 3 = 8).
04Rovesciare un array (senza un secondo array) medio

Consegna. Dato int[] a = {1, 2, 3, 4, 5, 6}; rovescia l'ordine degli elementi dentro lo stesso array, senza crearne un altro, e stampalo.

Output atteso:

6 5 4 3 2 1

Suggerimento: scambia il primo con l'ultimo, il secondo con il penultimo… Fino a dove devi arrivare?

Soluzione spiegata

Ragionamento

  1. Lo scambio tra due caselle richiede una variabile d'appoggio: se scrivessi a[i] = a[j]; a[j] = a[i]; perderei il valore di a[i] e avrei due caselle uguali. È come scambiare il contenuto di due bicchieri: serve un terzo bicchiere vuoto.
  2. La casella "specchio" di i è a.length - 1 - i: per i = 0 è l'ultima (5), per i = 1 la penultima (4), e così via.
  3. Mi fermo a metà (i < a.length / 2). Se arrivassi in fondo, la seconda metà dei giri rifarebbe gli scambi al contrario e l'array tornerebbe com'era.

Codice

public class Inverti {
    public static void main(String[] args) {
        int[] a = {1, 2, 3, 4, 5, 6};

        for (int i = 0; i < a.length / 2; i++) {
            int j = a.length - 1 - i;   // la casella "specchio"
            int tmp = a[i];
            a[i] = a[j];
            a[j] = tmp;
        }

        for (int x : a) {
            System.out.print(x + " ");
        }
        System.out.println();
    }
}

Prova a mano

Con 6 elementi a.length / 2 vale 3, quindi i giri sono i = 0, 1, 2: si scambiano (0,5), (1,4), (2,3). Con un numero dispari di elementi, per esempio 5, la divisione intera dà 2: si scambiano (0,4) e (1,3) e l'elemento centrale resta al suo posto, che è giusto.

Wrapper classes e conversioni

Ripasso lampoOgni primitivo ha la sua classe wrapper: int → Integer, double → Double, char → Character… Java converte da solo (autoboxing e unboxing). Integer.parseInt("25") trasforma un testo in numero. Teoria: Wrapper classes.
05Testo o numero? facile

Consegna. Scrivi cosa stampa ogni riga e per ognuna spiega se Java sta lavorando con testo o con numeri.

String a = "12";
String b = "3";
System.out.println(a + b);
System.out.println(Integer.parseInt(a) + Integer.parseInt(b));
System.out.println(a + Integer.parseInt(b) * 2);
System.out.println(Double.parseDouble(a) / 5);
System.out.println(Integer.parseInt(a) / 5);
System.out.println(Integer.toString(7) + 1);
Soluzione spiegata

Output

123
15
126
2.4
2
71

Riga per riga

  1. a + b: due String, il + le unisce: "12" e "3" diventano "123".
  2. Con parseInt diventano numeri, il + somma: 12 + 3 = 15.
  3. Prima si fa la moltiplicazione (precedenza): 3 * 2 = 6. Poi "12" + 6 è testo + numero, e vince il testo: "126".
  4. parseDouble dà 12.0; 12.0 / 5 è una divisione tra double: 2.4.
  5. Qui sono due int: la divisione è intera e butta via i decimali: 12 / 5 = 2.
  6. Integer.toString(7) è il testo "7"; più 1 diventa "71".
La regola del +Se almeno uno dei due operandi è una String, il + unisce. Se sono entrambi numeri, somma. Java valuta da sinistra a destra, rispettando la precedenza di * e /.
06Sommare numeri scritti come testo medio

Consegna. Un modulo ti consegna i dati come testo: String[] dati = {"10", "25", "7", "abc", "8"};. Calcola la somma dei soli valori numerici. Il valore "abc" non deve far fermare il programma: va segnalato e saltato. Alla fine stampa la somma e quanti valori sono stati scartati.

Output atteso:

"abc" non è un numero, lo salto
Somma: 50
Valori scartati: 1
Soluzione spiegata

Ragionamento

  1. Ogni elemento è una String: per sommarlo va convertito con Integer.parseInt.
  2. Integer.parseInt("abc") lancia NumberFormatException e, se nessuno la cattura, il programma si ferma. Quindi metto la conversione in un try e nel catch segnalo il problema.
  3. Il try-catch sta dentro il ciclo: così un valore sbagliato fa saltare solo quel giro, poi il ciclo continua con "8".

Codice

public class SommaArgomenti {
    public static void main(String[] args) {
        String[] dati = {"10", "25", "7", "abc", "8"};

        int somma = 0;
        int scartati = 0;
        for (String s : dati) {
            try {
                int n = Integer.parseInt(s);
                somma += n;
            } catch (NumberFormatException e) {
                System.out.println("\"" + s + "\" non è un numero, lo salto");
                scartati++;
            }
        }
        System.out.println("Somma: " + somma);
        System.out.println("Valori scartati: " + scartati);
    }
}

Dettagli

  • \" dentro una stringa stampa le virgolette.
  • Se il try-catch fosse fuori dal ciclo, al primo errore si uscirebbe dal ciclo e "8" non verrebbe mai sommato: la somma sarebbe 42 invece di 50.
  • Le eccezioni sono spiegate per bene nel capitolo Java: eccezioni; qui basta sapere che parseInt può fallire.
07La trappola del == con gli Integer difficile

Consegna. Esegui (o prevedi) questo codice. Una delle righe stampa un risultato che sembra sbagliato: quale, e perché? Come si confrontano correttamente due Integer?

Integer a = 100, b = 100;
Integer c = 1000, d = 1000;
System.out.println(a == b);
System.out.println(c == d);
System.out.println(c.equals(d));
int e = c;
System.out.println(e == d);
Soluzione spiegata

Output

true
false
true
true

Spiegazione

  • Integer è una classe: a, b, c, d sono riferimenti a oggetti. Con gli oggetti, == controlla se due variabili puntano allo stesso oggetto, non se il valore è uguale.
  • Per risparmiare memoria Java tiene pronti gli Integer da -128 a 127 e li riusa: per 100 a e b puntano allo stesso oggetto, quindi a == b è true "per caso".
  • 1000 è fuori da quell'intervallo: vengono creati due oggetti diversi e c == d dà false. È questa la riga che sembra sbagliata.
  • equals confronta il valore: true.
  • Nell'ultima riga e è un int: Java fa unboxing di d e confronta due numeri, quindi true.
RegolaPrimitivi (int, double…) si confrontano con ==. Oggetti (Integer, String…) con equals.

Metodi: void, parametri e return

Ripasso lampoUn metodo void fa qualcosa e non restituisce nulla. Un metodo con un tipo (int, double, boolean…) calcola un valore e lo restituisce con return. I parametri sono le variabili nell'intestazione, gli argomenti i valori passati nella chiamata. Teoria: I metodi.
08Metodi void: la cornice facile

Consegna. Scrivi due metodi void:

  • linea(int lunghezza) stampa una riga di * lunga lunghezza;
  • incornicia(String testo) stampa il testo dentro una cornice di asterischi, usando linea.

Nel main chiama incornicia("Ciao") e incornicia("Java è bello").

Output atteso:

********
* Ciao *
********
****************
* Java è bello *
****************
Soluzione spiegata

Ragionamento

  1. linea deve solo stampare, non restituire nulla: è void. Un ciclo stampa un asterisco per giro con print (senza andare a capo), poi un println() finale chiude la riga.
  2. Quanto deve essere lunga la cornice? La riga centrale è "* " + testo + " *": il testo più 4 caratteri (asterisco, spazio, spazio, asterisco). Quindi testo.length() + 4.
  3. incornicia riusa linea due volte: un metodo può chiamarne un altro. Così il codice della riga di asterischi è scritto una volta sola.

Codice

public class Cornice {

    static void linea(int lunghezza) {
        for (int i = 0; i < lunghezza; i++) {
            System.out.print("*");
        }
        System.out.println();
    }

    static void incornicia(String testo) {
        linea(testo.length() + 4);
        System.out.println("* " + testo + " *");
        linea(testo.length() + 4);
    }

    public static void main(String[] args) {
        incornicia("Ciao");
        incornicia("Java è bello");
    }
}

Da notare

  • testo.length() ha le parentesi perché per le String è un metodo; array.length no, perché per gli array è una proprietà. È un errore frequentissimo nelle verifiche.
  • I metodi sono static perché li chiamiamo direttamente dal main, senza creare oggetti.
09Tre metodi con return medio

Consegna. Scrivi questi tre metodi e provali nel main:

  • isPari(int n) restituisce true se n è pari;
  • potenza(int base, int esponente) calcola base elevato a esponente con un ciclo (niente Math.pow);
  • prezzoScontato(double prezzo, int percentuale) restituisce il prezzo dopo lo sconto.

Output atteso:

8 è pari? true
7 è pari? false
2^10 = 1024
3^0 = 1
80 euro col 25% di sconto: 60.0
Soluzione spiegata

Ragionamento, un metodo alla volta

  1. isPari: un numero è pari se il resto della divisione per 2 è 0, cioè n % 2 == 0. Questa espressione è già un boolean, quindi posso restituirla direttamente: non serve if (...) return true; else return false;.
  2. potenza: 210 è 2 moltiplicato per sé stesso 10 volte. Parto da risultato = 1 (non 0, altrimenti ogni moltiplicazione darebbe 0) e moltiplico esponente volte. Con esponente 0 il ciclo non gira mai e resta 1, che è proprio il risultato giusto (30 = 1).
  3. prezzoScontato: lo sconto è prezzo * percentuale / 100; lo tolgo dal prezzo. Il tipo di ritorno è double perché un prezzo può avere i centesimi.

Codice

public class Calcoli {

    static boolean isPari(int n) {
        return n % 2 == 0;
    }

    static int potenza(int base, int esponente) {
        int risultato = 1;
        for (int i = 0; i < esponente; i++) {
            risultato *= base;
        }
        return risultato;
    }

    static double prezzoScontato(double prezzo, int percentuale) {
        return prezzo - prezzo * percentuale / 100;
    }

    public static void main(String[] args) {
        System.out.println("8 è pari? " + isPari(8));
        System.out.println("7 è pari? " + isPari(7));
        System.out.println("2^10 = " + potenza(2, 10));
        System.out.println("3^0 = " + potenza(3, 0));
        System.out.println("80 euro col 25% di sconto: " + prezzoScontato(80, 25));
    }
}

Errori da evitare

  • In prezzoScontato scrivere percentuale / 100 * prezzo: 25 / 100 tra due int fa 0 e lo sconto sparisce. Mettendo prima prezzo (un double) il calcolo diventa decimale fin dall'inizio.
  • Chiamare un metodo con return senza usare il risultato (potenza(2, 10); da solo): il valore viene calcolato e buttato via.
10Trova l'errore: tre metodi che non compilano medio

Consegna. Nessuno di questi tre programmi compila. Per ognuno trova l'errore, spiega cosa dice il compilatore e correggilo.

A

public class Errore1 {
    static int doppio(int n) {
        int d = n * 2;
    }
    public static void main(String[] args) {
        System.out.println(doppio(4));
    }
}

B

public class Errore2 {
    static void saluta(String nome) {
        System.out.println("Ciao " + nome);
    }
    public static void main(String[] args) {
        String s = saluta("Anna");
    }
}

C

public class Errore3 {
    static double media(int a, int b) {
        return (a + b) / 2.0;
    }
    public static void main(String[] args) {
        System.out.println(media(5));
    }
}
Soluzione spiegata

A · manca il return

riga 4: error: missing return statement

Il metodo promette un int ("missing return statement" = manca l'istruzione return) ma calcola d e non lo restituisce. Correzione: return n * 2; (oppure aggiungere return d;).

B · un void non restituisce niente

riga 6: error: incompatible types: void cannot be converted to String

saluta è void: stampa, ma non produce un valore da mettere in s ("incompatible types: void cannot be converted to String"). Correzione: chiamarlo da solo, saluta("Anna");. Se davvero serve il testo, il metodo va riscritto con String e return "Ciao " + nome;.

C · argomenti sbagliati

riga 6: error: method media in class Errore3 cannot be applied to given types;

Il metodo ha due parametri ma viene chiamato con un argomento. Gli argomenti devono essere tanti quanti i parametri, dello stesso tipo e nello stesso ordine. Correzione: media(5, 8).

Metodi che lavorano sugli array

Ripasso lampoUn array si può passare a un metodo come parametro (static int somma(int[] v)) e un metodo può anche restituirne uno (static int[] copia(...)). Attenzione: il metodo riceve lo stesso array, non una copia, quindi se lo modifica la modifica si vede anche fuori. Teoria: Metodi e array.
11Il contapassi medio

Consegna. L'array int[] passi = {4200, 8700, 6100, 12000, 3500, 9800, 7400}; contiene i passi fatti in una settimana. Scrivi quattro metodi, ognuno con un solo compito:

  • somma(int[] v): il totale;
  • media(int[] v): la media, con i decimali (riusa somma);
  • minimo(int[] v): il valore più piccolo;
  • quantiSopra(int[] v, double soglia): quanti valori superano la soglia.

Il main stampa totale, media, giorno peggiore e quanti giorni sono sopra la media.

Output atteso:

Totale passi: 51700
Media: 7385.714285714285
Giorno peggiore: 3500
Giorni sopra la media: 4
Soluzione spiegata

Ragionamento

  1. somma: accumulatore che parte da 0, sommo ogni elemento.
  2. media: somma / length. Sono due int, quindi la divisione sarebbe intera (51700 / 7 = 7385, senza decimali). Con il cast (double) trasformo la somma in double prima di dividere.
  3. minimo: parto dal primo elemento v[0] (non da 0! con valori tutti positivi 0 vincerebbe sempre) e lo sostituisco ogni volta che trovo un valore più piccolo.
  4. quantiSopra: un contatore con una condizione, come nell'esercizio dei voti. La soglia è double perché le passo la media.
  5. Nel main calcolo la media una volta, la salvo in m e la riuso.

Codice

public class Statistiche {

    static int somma(int[] v) {
        int s = 0;
        for (int x : v) {
            s += x;
        }
        return s;
    }

    static double media(int[] v) {
        return (double) somma(v) / v.length;
    }

    static int minimo(int[] v) {
        int min = v[0];
        for (int x : v) {
            if (x < min) {
                min = x;
            }
        }
        return min;
    }

    static int quantiSopra(int[] v, double soglia) {
        int c = 0;
        for (int x : v) {
            if (x > soglia) {
                c++;
            }
        }
        return c;
    }

    public static void main(String[] args) {
        int[] passi = {4200, 8700, 6100, 12000, 3500, 9800, 7400};
        double m = media(passi);
        System.out.println("Totale passi: " + somma(passi));
        System.out.println("Media: " + m);
        System.out.println("Giorno peggiore: " + minimo(passi));
        System.out.println("Giorni sopra la media: " + quantiSopra(passi, m));
    }
}

Perché dividere in metodi

Ogni metodo si legge e si controlla da solo, e si può riusare: media usa somma invece di riscrivere il ciclo. Se domani i dati fossero i voti di una classe, i quattro metodi andrebbero bene senza cambiare una riga.

12Il metodo modifica l'originale? difficile

Consegna. Prevedi l'output di questo programma e spiega perché azzera cambia l'array del main, mentre azzeraNumero non cambia x.

public class Riferimento {

    static void azzera(int[] v) {
        for (int i = 0; i < v.length; i++) {
            v[i] = 0;
        }
    }

    static void azzeraNumero(int n) {
        n = 0;
    }

    static int[] raddoppiaCopia(int[] v) {
        int[] nuovo = new int[v.length];
        for (int i = 0; i < v.length; i++) {
            nuovo[i] = v[i] * 2;
        }
        return nuovo;
    }

    public static void main(String[] args) {
        int x = 5;
        azzeraNumero(x);
        System.out.println("x = " + x);

        int[] a = {1, 2, 3};
        int[] b = raddoppiaCopia(a);
        System.out.println("a[0] = " + a[0] + ", b[0] = " + b[0]);

        azzera(a);
        System.out.println("a[0] = " + a[0] + ", b[0] = " + b[0]);
    }
}
Soluzione spiegata

Output

x = 5
a[0] = 1, b[0] = 2
a[0] = 0, b[0] = 2

Spiegazione

  • Primitivi: azzeraNumero(x) riceve una copia del valore 5. Dentro il metodo n diventa 0, ma è una variabile sua: x nel main resta 5.
  • Array: la variabile a non contiene i numeri, contiene l'indirizzo dell'array in memoria. Il metodo riceve una copia dell'indirizzo, cioè punta allo stesso array. Quando scrive v[i] = 0 modifica le caselle dell'unico array che esiste, e il main lo vede.
  • raddoppiaCopia invece crea un array nuovo con new e lo restituisce. b punta a quello, quindi azzerare a non tocca b: b[0] resta 2.
Un paragonePassare un int è come dare a un amico una fotocopia di un foglio: se ci scrive sopra, il tuo originale non cambia. Passare un array è come dargli l'indirizzo di casa tua: se va lì e sposta i mobili, li trovi spostati anche tu.

Overload dei metodi

Ripasso lampoL'overload è avere più metodi con lo stesso nome ma parametri diversi (numero, tipo o ordine). Java sceglie quale usare guardando gli argomenti. Il tipo di ritorno da solo non basta a distinguerli. Teoria: Overload dei metodi.
13Un nome, tre aree medio

Consegna. Scrivi tre versioni del metodo area (overload):

  • area(double lato): area del quadrato;
  • area(double base, double altezza): area del rettangolo;
  • area(double base, double altezza, String forma): se forma è "triangolo" calcola l'area del triangolo, altrimenti quella del rettangolo (riusando la seconda versione).

Output atteso:

Quadrato di lato 3: 9.0
Rettangolo 4 x 2.5: 10.0
Triangolo 6 x 4: 12.0
Forma sconosciuta 6 x 4: 24.0
Soluzione spiegata

Ragionamento

  1. Le tre versioni hanno lo stesso nome ma un numero diverso di parametri (1, 2, 3): è un overload valido e Java non può confonderle.
  2. Nella terza versione confronto le stringhe con equals, non con ==.
  3. Se la forma non è un triangolo, invece di riscrivere base * altezza chiamo area(base, altezza): Java vede due argomenti e sceglie la versione del rettangolo.

Codice

public class Area {

    // quadrato: un lato
    static double area(double lato) {
        return lato * lato;
    }

    // rettangolo: base e altezza
    static double area(double base, double altezza) {
        return base * altezza;
    }

    // triangolo: base, altezza e un testo che lo indica
    static double area(double base, double altezza, String forma) {
        if (forma.equals("triangolo")) {
            return base * altezza / 2;
        }
        return area(base, altezza);
    }

    public static void main(String[] args) {
        System.out.println("Quadrato di lato 3: " + area(3));
        System.out.println("Rettangolo 4 x 2.5: " + area(4, 2.5));
        System.out.println("Triangolo 6 x 4: " + area(6, 4, "triangolo"));
        System.out.println("Forma sconosciuta 6 x 4: " + area(6, 4, "rombo"));
    }
}

Da notare

  • area(3) passa un int a un parametro double: Java lo allarga da solo (3 diventa 3.0), per questo stampa 9.0.
  • Il vantaggio dell'overload: chi usa il codice ricorda un solo nome, area, e passa i dati che ha.
14Quale versione viene chiamata? difficile

Consegna. Una classe ha questi cinque metodi:

public class QualeVersione {
    static void stampa(int x)              { System.out.println("A: int " + x); }
    static void stampa(double x)           { System.out.println("B: double " + x); }
    static void stampa(String s)           { System.out.println("C: String " + s); }
    static void stampa(int x, String s)    { System.out.println("D: int, String"); }
    static void stampa(String s, int x)    { System.out.println("E: String, int"); }

    public static void main(String[] args) {
        stampa(5);
        stampa(5.0);
        stampa("5");
        stampa(5, "cinque");
        stampa("cinque", 5);
        stampa('A');
    }
}

1) Per ogni chiamata del main scrivi quale versione (A–E) viene eseguita. Attenzione all'ultima.

2) Perché questa coppia di metodi, invece, non compila?

public class NonOverload {
    static int calcola(int a) {
        return a * 2;
    }
    static double calcola(int a) {
        return a * 2.5;
    }
}
Soluzione spiegata

1 · Output

A: int 5
B: double 5.0
C: String 5
D: int, String
E: String, int
A: int 65
  • 5 è un int → A. 5.0 è un double → B. "5" è una String → C.
  • Con due argomenti conta anche l'ordine: (int, String) → D, (String, int) → E. D ed E sono overload validi proprio perché l'ordine dei tipi è diverso.
  • 'A' è un char. Non c'è una versione con char, quindi Java cerca la più vicina in cui può convertirlo senza perdere informazioni: il char diventa l'int 65 (il suo codice) e viene scelta A. Sorpresa: stampa 65, non A!

2 · Perché non compila

riga 5: error: method calcola(int) is already defined in class NonOverload

I due metodi hanno lo stesso nome e gli stessi parametri (int a): cambia solo il tipo di ritorno. Quando scrivi calcola(4) Java non avrebbe modo di sapere quale dei due vuoi, quindi lo vieta ("already defined" = già definito). Per l'overload devono cambiare i parametri.

Esercizio completo: il registro di classe

Questo esercizio mette insieme tutto il capitolo: array, length, for e foreach, wrapper e parseInt, metodi void e con return, metodi che ricevono e restituiscono array, overload. È lungo come una verifica: fallo a pezzi, un metodo alla volta, e prova ogni pezzo prima di andare avanti.

15Il registro di classe completo

Consegna. Il registro elettronico esporta i voti di tre studenti come testo:

String[] nomi = {"Anna", "Bruno", "Carla"};
String[][] dati = {
    {"7", "8", "9", "8"},
    {"5", "6", "4", "6"},
    {"6", "7", "6", "5"},
};

(dati[0] sono i voti di Anna, dati[1] quelli di Bruno e così via.) Scrivi un programma che:

  1. con un metodo converti(String[] testi) trasformi i voti di ogni studente in un int[] (restituisce un array);
  2. con metodi separati calcoli media (con decimali), voto massimo e numero di sufficienze;
  3. abbia un metodo giudizio in overload: una versione riceve la media (double), l'altra l'array dei voti. Il giudizio è "ottimo" da 8 in su, "sufficiente" da 6 in su, altrimenti "insufficiente";
  4. con metodi void stampi per ogni studente una scheda con i voti separati da virgola;
  5. alla fine dica chi ha la media più alta.

Output atteso:

Anna: 7, 8, 9, 8
  media 8.00, voto migliore 9, sufficienze 4 su 4 -> ottimo
Bruno: 5, 6, 4, 6
  media 5.25, voto migliore 6, sufficienze 2 su 4 -> insufficiente
Carla: 6, 7, 6, 5
  media 6.00, voto migliore 7, sufficienze 3 su 4 -> sufficiente
Media più alta: Anna
Giudizio su media 6.5: sufficiente
Soluzione spiegata

Passo 1 · Progettare prima di scrivere

Prima di scrivere codice, elenco i compiti e do a ognuno un metodo. È la parte più importante: se i metodi sono piccoli e chiari, il resto è facile.

MetodoRiceveRestituisceArgomento del capitolo

Passo 2 · La conversione

converti crea un array di int lungo quanto quello di testi (new int[testi.length]) e lo riempie casella per casella con Integer.parseInt. Serve il for classico perché devo scrivere nella casella i del nuovo array.

Passo 3 · I calcoli

Sono gli stessi schemi degli esercizi precedenti: accumulatore per la somma, cast (double) per avere i decimali nella media, massimo che parte dal primo elemento, contatore con if.

Passo 4 · L'overload di giudizio

La versione con il double contiene la logica. Quella con l'array non la ripete: calcola la media e chiama l'altra versione. Così se un giorno cambiano le soglie, si modifica un punto solo. Gli if sono in ordine dal più alto: appena uno è vero, il return esce dal metodo e gli altri non vengono controllati.

Passo 5 · La stampa

In stampaVoti la virgola va messa tra i voti, non dopo l'ultimo: per questo uso il for classico e controllo i < voti.length - 1. scheda usa printf per mostrare la media con due decimali (%.2f); %d è per gli interi, %s per il testo e %n va a capo. Su un computer impostato in italiano printf usa la virgola come separatore decimale e stampa 8,00 invece di 8.00: è normale.

Passo 6 · Il main e la media più alta

Per ogni studente i converto dati[i], stampo la scheda e salvo la media in un array medie. Poi cerco l'indice della media più alta (non il valore): partendo da 0, se trovo una media maggiore aggiorno l'indice. Con l'indice recupero il nome da nomi[migliore]. Funziona perché i due array sono paralleli: la posizione i indica lo stesso studente in entrambi.

Codice completo

public class Registro {

    // ---------- conversione: wrapper e parseInt ----------
    static int[] converti(String[] testi) {
        int[] voti = new int[testi.length];
        for (int i = 0; i < testi.length; i++) {
            voti[i] = Integer.parseInt(testi[i]);
        }
        return voti;
    }

    // ---------- calcoli: metodi con return ----------
    static double media(int[] voti) {
        int somma = 0;
        for (int v : voti) {
            somma += v;
        }
        return (double) somma / voti.length;
    }

    static int massimo(int[] voti) {
        int max = voti[0];
        for (int v : voti) {
            if (v > max) {
                max = v;
            }
        }
        return max;
    }

    static int contaSufficienti(int[] voti) {
        int c = 0;
        for (int v : voti) {
            if (v >= 6) {
                c++;
            }
        }
        return c;
    }

    // ---------- overload: stessa idea, dati diversi ----------
    static String giudizio(double media) {
        if (media >= 8) return "ottimo";
        if (media >= 6) return "sufficiente";
        return "insufficiente";
    }

    static String giudizio(int[] voti) {
        return giudizio(media(voti));
    }

    // ---------- stampa: metodi void ----------
    static void stampaVoti(String nome, int[] voti) {
        System.out.print(nome + ": ");
        for (int i = 0; i < voti.length; i++) {
            System.out.print(voti[i]);
            if (i < voti.length - 1) {
                System.out.print(", ");
            }
        }
        System.out.println();
    }

    static void scheda(String nome, int[] voti) {
        stampaVoti(nome, voti);
        System.out.printf("  media %.2f, voto migliore %d, sufficienze %d su %d -> %s%n",
                media(voti), massimo(voti), contaSufficienti(voti), voti.length, giudizio(voti));
    }

    public static void main(String[] args) {
        String[] nomi = {"Anna", "Bruno", "Carla"};
        String[][] dati = {
            {"7", "8", "9", "8"},
            {"5", "6", "4", "6"},
            {"6", "7", "6", "5"},
        };

        double[] medie = new double[nomi.length];
        for (int i = 0; i < nomi.length; i++) {
            int[] voti = converti(dati[i]);
            scheda(nomi[i], voti);
            medie[i] = media(voti);
        }

        int migliore = 0;
        for (int i = 1; i < medie.length; i++) {
            if (medie[i] > medie[migliore]) {
                migliore = i;
            }
        }
        System.out.println("Media più alta: " + nomi[migliore]);
        System.out.println("Giudizio su media 6.5: " + giudizio(6.5));
    }
}

  • Perché giudizio(6.5) e giudizio(voti) non si confondono? (Tipi diversi del parametro: double e int[].)
