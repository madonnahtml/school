I cicli in C

Un ciclo ripete un blocco di istruzioni finché una condizione è vera. In C ce ne sono tre: for, while e do-while.

Il ciclo for

Si usa quando sai in anticipo quante volte ripetere. Nell'intestazione ci sono tre parti separate da punto e virgola: inizializzazione, condizione, aggiornamento.

#include <stdio.h>

int main(void) {
    // stampa i numeri da 1 a 5
    for (int i = 1; i <= 5; i++) {
        printf("%d\n", i);
    }
    return 0;
}
TruccoLeggi il for così: «parti da i = 1, finché i ≤ 5, e ogni giro fai i++».

Il ciclo while

Controlla la condizione prima di ogni giro. Se è falsa già all'inizio, il corpo non viene mai eseguito. Si usa quando non sai quante volte ripetere.

int n = 0;
scanf("%d", &n);
while (n < 0) {            // continua finché il numero è negativo
    printf("Inserisci un numero positivo: ");
    scanf("%d", &n);
}

Il ciclo do-while

Controlla la condizione dopo ogni giro, quindi il corpo viene eseguito almeno una volta. È perfetto per i menu e per controllare l'input.

int scelta;
do {
    printf("1) Gioca  2) Esci\n");
    scanf("%d", &scelta);
} while (scelta != 2);
DefinizioneUn ciclo infinito è un ciclo la cui condizione non diventa mai falsa, per esempio while (1). Si interrompe solo con break o chiudendo il programma.

break e continue

IstruzioneCosa fa
breakEsce subito dal ciclo.
continueSalta il resto del giro e passa al successivo.

Esercizi

01Somma da 1 a N facile

Leggi un intero N e stampa la somma dei numeri da 1 a N.

Soluzione 
int n, somma = 0;
scanf("%d", &n);
for (int i = 1; i <= n; i++) {
    somma += i;
}
printf("Somma: %d\n", somma);

Con N = 4 la somma è 1 + 2 + 3 + 4 = 10.

02Numeri pari facile

Stampa tutti i numeri pari da 2 a 20 usando un ciclo while.

Soluzione 
int i = 2;
while (i <= 20) {
    printf("%d ", i);
    i += 2;
}
03Fattoriale medio

Leggi un intero n ≥ 0 e calcola n! (il prodotto dei numeri da 1 a n; per definizione 0! = 1). Controlla l'input con un do-while.

Soluzione 
int n;
do {
    printf("n (>= 0): ");
    scanf("%d", &n);
} while (n < 0);

long long fatt = 1;
for (int i = 2; i <= n; i++) {
    fatt *= i;
}
printf("%d! = %lld\n", n, fatt);

Uso long long perché il fattoriale cresce molto in fretta: 13! supera già il massimo di un int a 32 bit.
