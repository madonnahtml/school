Java: programmazione a oggetti

Fino a ora i programmi erano fatti di variabili e metodi sparsi. Con la programmazione a oggetti si raggruppano i dati e le azioni che li riguardano in un'unica "scatola": prima si disegna il modello (la classe), poi si costruiscono tante copie concrete (gli oggetti).

Prima di cominciareServono gli array e i metodi: se li hai dimenticati, ripassali in Java: array, wrapper, metodi e overload. Qui useremo anche l'overload, ma applicato ai costruttori.

Che cos'è la programmazione a oggetti

In una frase La OOP (Object Oriented Programming) è un modo di scrivere programmi che organizza il codice attorno a oggetti: elementi del mondo reale o concetti astratti. Ogni oggetto ha proprietà (gli attributi) e comportamenti (i metodi).

Proprietà (attributi)

Descrivono com'è l'oggetto: nome, età, colore, velocità…

Sono i sostantivi e gli aggettivi.

Comportamenti (metodi)

Descrivono cosa sa fare: studia(), accelera(), calcolaMedia()…

Sono i verbi.

Esempi di oggetti: Studente, Automobile, Computer, Libro, ContoBancario, Persona.

Un trucco per cominciarePer progettare una classe, descrivi la cosa a parole e sottolinea: i sostantivi diventano attributi ("lo studente ha un nome, un'età e una media"), i verbi diventano metodi ("lo studente studia, saluta, calcola la media").

Classe e oggetto

È la distinzione più importante di tutta la OOP:

La classe (il modello)

Descrive come sarà fatto un oggetto: quali attributi possiede e quali metodi può eseguire. Esiste una volta sola.

È lo stampino dei biscotti.

L'oggetto (l'istanza)

È una realizzazione concreta della classe, con valori propri. Da una classe si possono creare infiniti oggetti.

Sono i biscotti.

Classe AutomobileOggetti (istanze)
Attributi: marca, modello, colore, velocita
Metodi: accelera(), frena(), stampaInfo()		Fiat Panda, rossa, 120 km/h
BMW Serie 1, nera, 180 km/h
Toyota Yaris, bianca, 90 km/h

Tre automobili diverse, ma tutte costruite con lo stesso stampino: hanno gli stessi attributi, con valori diversi. Cambiare la velocità della Panda non cambia quella della BMW.

Un paragoneLa classe è la ricetta della torta; gli oggetti sono le torte che ne escono. Nessuno mangia una ricetta, e da una ricetta si possono fare quante torte vuoi.

Creare una classe e gli attributi

Gli attributi sono le caratteristiche dell'oggetto. In Java si dichiarano dentro la classe ma fuori dai metodi, direttamente nel corpo. Ogni oggetto ha i suoi valori indipendenti.

public class Studente {
    String nome;
    String cognome;
    int eta;
    double media;
}

Questa classe è solo un modello: da sola non fa niente, descrive soltanto com'è fatto uno studente. Due studenti creati da qui avranno dati propri, ad esempio:

  • Studente 1: Marco Rossi, 18 anni, media 7.5
  • Studente 2: Luca Bianchi, 19 anni, media 8.2
Regola da ricordarePer convenzione i nomi delle classi iniziano con la maiuscola (Studente, ContoBancario); i nomi di attributi, metodi e variabili con la minuscola (nome, calcolaMedia). Una classe public sta in un file con lo stesso nome: Studente.java.

Creare oggetti e accedere agli attributi

Per creare un oggetto si usa la parola chiave new. Per raggiungere un attributo o un metodo di quell'oggetto si usa l'operatore punto ..

Studente studente1 = new Studente();
Studente studente2 = new Studente();
Studente studente3 = new Studente();

Ogni oggetto è un'istanza indipendente della classe Studente. Si possono creare quanti se ne vogliono.

Studente studente1 = new Studente(); 
studente1.nome = "Marco";
studente1.cognome = "Rossi";
studente1.eta = 18;

System.out.println(studente1.nome);
// Output: Marco

Il punto collega l'oggetto al suo attributo o metodo: si legge "il nome di studente1".

Un programma completo

Le due classi stanno in due file (o in uno solo, se la seconda non è public). La classe con il metodo main è quella da cui parte il programma.

// Studente.java
public class Studente {
    String nome;
    int eta;
}

// Main.java
public class Main {
    public static void main(String[] args) {
        Studente s1 = new Studente();
        s1.nome = "Marco";
        s1.eta = 18;

        Studente s2 = new Studente();
        s2.nome = "Luca";
        s2.eta = 19;

        System.out.println(s1.nome + " ha " + s1.eta + " anni");  // Marco ha 18 anni
        System.out.println(s2.nome + " ha " + s2.eta + " anni");  // Luca ha 19 anni
    }
}

Variabili che puntano agli oggetti

Una variabile di tipo classe (Studente s1) non contiene l'oggetto: contiene un riferimento, cioè il "numero di telefono" per trovarlo. Per questo copiare la variabile non copia l'oggetto:

Studente a = new Studente();
a.nome = "Anna";

Studente b = a;        // b punta allo STESSO oggetto
b.nome = "Giulia";

System.out.println(a.nome);   // Giulia  (è lo stesso oggetto!)
AttenzioneStudente b = a; non crea un secondo studente: crea un secondo nome per lo stesso studente. Un nuovo oggetto nasce solo con new.

I metodi: cosa può fare un oggetto

Se gli attributi dicono cosa è l'oggetto, i metodi dicono cosa può fare. Un metodo può non restituire niente (void), ricevere dei parametri e restituire un valore con return. Si scrivono dentro la classe, e di solito senza static: appartengono all'oggetto.

1 · Metodo void

void studia() {
    System.out.println(nome + " sta studiando.");
}

Fa qualcosa e non restituisce nulla.

2 · Metodo con parametri

void saluta(String persona) {
    System.out.println("Ciao " + persona);
}

Riceve dei dati da usare.

3 · Metodo con return

double calcolaMedia(double v1, double v2) {
    return (v1 + v2) / 2;
}

Restituisce un risultato a chi lo chiama.

Un metodo si chiama con l'operatore punto, sull'oggetto che deve eseguirlo. Dentro il metodo, gli attributi dell'oggetto si usano direttamente per nome (nome in studia()):

Studente s1 = new Studente();
s1.nome = "Marco";

s1.studia();                      // Marco sta studiando.
s1.saluta("Anna");                // Ciao Anna
s1.media = s1.calcolaMedia(7, 8); // media = 7.5
Chi sta eseguendo?Lo stesso metodo dà risultati diversi su oggetti diversi: s1.studia() stampa "Marco sta studiando", s2.studia() stampa "Luca sta studiando". Il metodo è uno solo, ma lavora sugli attributi dell'oggetto a cui è stato chiamato.

Il costruttore e la parola chiave this

Creare un oggetto e poi riempire gli attributi a uno a uno è lungo e ci si può dimenticare qualcosa. Per questo esiste il costruttore: un metodo speciale eseguito automaticamente quando si scrive new, che serve a inizializzare l'oggetto.

  • ha lo stesso nome della classe;
  • non ha nessun tipo di ritorno, nemmeno void;
  • può avere dei parametri, con i dati con cui nasce l'oggetto.
public class Studente {
    String nome;
    int eta;

    Studente(String nome, int eta) {
        this.nome = nome;
        this.eta = eta;
    }
}

Ora un oggetto nasce già completo:

Studente s1 = new Studente("Marco", 18);
Studente s2 = new Studente("Luca", 19);

A cosa serve this

Nel costruttore sopra, il parametro si chiama nome e anche l'attributo si chiama nome. Per Java, dentro il costruttore, nome è il parametro (la variabile più vicina). La parola chiave this significa "questo oggetto" e risolve l'ambiguità:

ScritturaCosa indica
this.nomel'attributo dell'oggetto
nomeil parametro ricevuto

Quindi this.nome = nome; si legge: "l'attributo nome di questo oggetto riceve il valore del parametro nome".

Errore classicoSe scrivi solo nome = nome; il compilatore non protesta, ma assegni il parametro a se stesso e l'attributo resta null. Quando parametro e attributo hanno lo stesso nome serve sempre this..

Overload dei costruttori

Si possono scrivere più costruttori nella stessa classe, ciascuno con una lista di parametri diversa (per numero o per tipo). Java sceglie da solo quello giusto guardando gli argomenti passati a new. Si chiama constructor overloading: è lo stesso overload dei metodi, applicato ai costruttori.

public class Studente {
    String nome;
    int eta;

    // 1 · costruttore vuoto
    Studente() {
        nome = "Sconosciuto";
        eta = 0;
    }

    // 2 · solo il nome
    Studente(String nome) {
        this.nome = nome;
        eta = 0;
    }

    // 3 · completo
    Studente(String nome, int eta) {
        this.nome = nome;
        this.eta = eta;
    }
}
Studente a = new Studente();               // usa il costruttore 1
Studente b = new Studente("Marco");        // usa il costruttore 2
Studente c = new Studente("Marco", 18);    // usa il costruttore 3
Attenzione: il costruttore vuoto sparisceSe in una classe non scrivi nessun costruttore, Java ne crea uno vuoto per te (per questo new Studente() funzionava all'inizio). Ma appena ne definisci almeno uno tuo, Java non fornisce più quello vuoto: se lo vuoi usare, devi scriverlo tu.
public class Studente {
    String nome;
    Studente(String nome) { this.nome = nome; }
}

Studente s = new Studente();   // ERRORE di compilazione: manca il costruttore vuoto

Approfondimento: this(...) per non ripetere il codice

I tre costruttori ripetono quasi le stesse righe. Con this(...) un costruttore può chiamarne un altro della stessa classe (deve essere la prima riga):

Studente() {
    this("Sconosciuto", 0);      // chiama il costruttore completo
}

Studente(String nome) {
    this(nome, 0);
}

Studente(String nome, int eta) {  // l'unico che assegna davvero
    this.nome = nome;
    this.eta = eta;
}

Questa parte è un'aggiunta alle slide: non è richiesta per capire il resto.

Scope delle variabili

Lo scope (ambito) indica la zona del programma in cui una variabile è visibile, cioè dove la puoi usare.

Tipo di variabileDove è visibileDove si dichiara
Attributiin tutta la classe (in tutti i suoi metodi)nel corpo della classe, fuori dai metodi
Parametrisolo dentro il metodo che li ricevenell'intestazione del metodo
Variabili localisolo nel blocco { } in cui sono dichiaratedentro un metodo, un if, un for…
 
public class Studente {
    String nome;                          // attributo: visibile ovunque nella classe

    void presenta(String saluto) {        // saluto: parametro, visibile solo qui
        String frase = saluto + " " + nome;   // frase: variabile locale
        System.out.println(frase);
    }

    void altro() {
        // System.out.println(frase);     // ERRORE: frase esiste solo in presenta()
        System.out.println(nome);         // OK: è un attributo
    }
}
Per ricordarloUna variabile nasce alla sua dichiarazione e muore alla graffa } che chiude il blocco in cui è nata. Gli attributi vivono quanto l'oggetto; parametri e variabili locali, solo il tempo di esecuzione del metodo.

Array di oggetti

Come si fa con i numeri, anche gli oggetti si possono mettere in un array: utile per gestire una classe intera, un elenco di auto, un catalogo di libri.

Studente[] classe = new Studente[5];

// Ogni elemento va inizializzato!
classe[0] = new Studente("Marco", 18);
classe[1] = new Studente("Luca", 19);

// Accesso con ciclo for-each
for (Studente s : classe) {
    System.out.println(s.nome);
}
Il trabocchetto dei riferimentinew Studente[5] crea solo 5 caselle vuote (i riferimenti, inizialmente null), non 5 studenti. Gli oggetti veri vanno creati uno per uno con new Studente(...).

Nell'esempio sopra le caselle 2, 3 e 4 sono ancora null: il ciclo for-each arriva alla casella 2 e il programma si ferma con un errore, la NullPointerException (si è provato a usare .nome su "nessun oggetto").

Studente[] classe = new Studente[5];
System.out.println(classe[0]);       // null
System.out.println(classe[0].nome);  // NullPointerException!

Due soluzioni: riempire tutte le caselle prima di scorrere l'array, oppure controllare prima di usare l'elemento:

for (Studente s : classe) {
    if (s != null) {                 // salta le caselle vuote
        System.out.println(s.nome);
    }
}
CollegamentoAnche String[] è un array di oggetti: una casella non inizializzata vale null, non la stringa vuota "". Gli array in generale sono nella pagina precedente.

Mappa riassuntiva

  • OOP: il codice è organizzato in oggetti con attributi (cosa sono) e metodi (cosa fanno).
  • Classe = modello, oggetto = istanza concreta con valori propri. Da una classe nascono infiniti oggetti.
  • Attributi: dichiarati nel corpo della classe, fuori dai metodi.
  • new crea l'oggetto, l'operatore punto . raggiunge attributi e metodi.
  • Metodi: void (non restituisce), con parametri, con return.
  • Costruttore: stesso nome della classe, nessun tipo di ritorno, eseguito da new per inizializzare l'oggetto.
  • this = questo oggetto: this.nome è l'attributo, nome il parametro.
  • Overload dei costruttori: più costruttori con parametri diversi; se ne scrivi uno, Java non crea più quello vuoto.
  • Scope: attributi (tutta la classe), parametri (il metodo), variabili locali (il blocco).
  • Array di oggetti: new Studente[5] crea solo riferimenti null; ogni elemento va creato con new.

Esercizi

01Classe o oggetto? facile

Per ogni coppia, di' quale è la classe e quale l'oggetto: a) Libro / "I promessi sposi"; b) la tua bicicletta / Bicicletta; c) Studente / new Studente("Luca", 19).

Soluzione

a) classe Libro, oggetto "I promessi sposi". b) classe Bicicletta, oggetto la tua bicicletta. c) classe Studente, oggetto quello creato da new Studente("Luca", 19).

La classe è il modello (un concetto generale, scritto con la maiuscola), l'oggetto è un caso concreto.

02Cosa stampa? medio
Studente a = new Studente("Anna", 17);
Studente b = new Studente("Anna", 17);
Studente c = a;

c.nome = "Giulia";
b.eta = 20;

System.out.println(a.nome);
System.out.println(b.nome);
System.out.println(a.eta);
Soluzione

Stampa Giulia, poi Anna, poi 17.

  • c = a non crea un nuovo oggetto: c e a puntano allo stesso studente, quindi cambiare c.nome cambia anche a.nome.
  • b è un oggetto diverso (creato con un suo new): il suo nome resta Anna, e cambiare b.eta non tocca a.eta, che resta 17.
03Trova gli errori medio
public class Libro {
    String titolo;
    int pagine;

    void Libro(String titolo, int pagine) {
        titolo = titolo;
        this.pagine = pagine;
    }
}

Libro l = Libro("Dune", 600);

Trova i tre errori e scrivi la versione corretta.

Soluzione
  1. void Libro(...): un costruttore non ha tipo di ritorno, nemmeno void. Con void è un metodo normale che per caso si chiama come la classe, e non viene eseguito da new.
  2. titolo = titolo;: assegna il parametro a se stesso; serve this.titolo = titolo;.
  3. Libro("Dune", 600): manca new. Si scrive new Libro("Dune", 600).
public class Libro {
    String titolo;
    int pagine;

    Libro(String titolo, int pagine) {
        this.titolo = titolo;
        this.pagine = pagine;
    }
}

Libro l = new Libro("Dune", 600);
04Il costruttore sparito medio
public class Persona {
    String nome;
    Persona(String nome) { this.nome = nome; }
}

Persona p1 = new Persona("Sara");
Persona p2 = new Persona();

Quale riga non compila e perché? Come si risolve?

Soluzione

Non compila new Persona(). Appena la classe ha un costruttore scritto da noi, Java non fornisce più quello vuoto. Si risolve aggiungendolo (overload):

Persona() {
    nome = "Sconosciuto";
}
05La classe Libro medio

Scrivi la classe Libro con gli attributi titolo (String), autore (String) e pagine (int); un costruttore con i tre parametri; un metodo descrizione() che restituisce una stringa del tipo "Dune di Frank Herbert (600 pagine)". Nel main crea due libri e stampa le loro descrizioni.

Soluzione
public class Libro {
    String titolo;
    String autore;
    int pagine;

    Libro(String titolo, String autore, int pagine) {
        this.titolo = titolo;
        this.autore = autore;
        this.pagine = pagine;
    }

    String descrizione() {
        return titolo + " di " + autore + " (" + pagine + " pagine)";
    }

    public static void main(String[] args) {
        Libro l1 = new Libro("Dune", "Frank Herbert", 600);
        Libro l2 = new Libro("Lo Hobbit", "J.R.R. Tolkien", 310);
        System.out.println(l1.descrizione());
        System.out.println(l2.descrizione());
    }
}

descrizione() usa return perché restituisce il testo a chi lo chiama, che poi decide cosa farne (qui lo stampa). Gli attributi si usano per nome, senza this, perché nel metodo non ci sono parametri con lo stesso nome.

06La media della classe ragionamento
Studente[] classe = new Studente[4];
classe[0] = new Studente("Marco", 18);
classe[1] = new Studente("Luca", 19);

double somma = 0;
for (Studente s : classe) {
    somma += s.eta;
}
System.out.println(somma / classe.length);

a) Cosa succede eseguendo il programma? b) Correggilo per calcolare l'età media dei soli studenti presenti.

Soluzione

a) Il ciclo funziona per Marco e Luca, ma alla terza casella s vale null e s.eta provoca una NullPointerException: new Studente[4] ha creato solo 4 caselle vuote.

b) Si saltano le caselle vuote e si divide per il numero di studenti veri, non per classe.length:

double somma = 0;
int presenti = 0;
for (Studente s : classe) {
    if (s != null) {
        somma += s.eta;
        presenti++;
    }
}
System.out.println(somma / presenti);   // 18.5
07Esercitazione pratica: la classe Automobile completo

Mettiamo tutto insieme. Crea la classe Automobile con attributi, costruttori in overload, metodi e un array di oggetti nel main.

AttributiString marca, String modello, int anno, double velocita
CostruttoriAutomobile(), Automobile(marca, modello), Automobile(marca, modello, anno) — usa this!
Metodiaccelera(incremento), frena(decremento), stampaInfo()
Nel mainAutomobile[] auto = new Automobile[3];, poi auto[0] = new Automobile("Fiat", "Panda", 2020); e così via; infine un ciclo for-each per stampare tutte le auto

Come procedere: 1) scrivi attributi e un costruttore alla volta, controllando che compili; 2) aggiungi i tre metodi; 3) nel main crea l'array e riempi tutte le caselle prima di stampare; 4) fai accelerare e frenare qualche auto e stampa il risultato.

Soluzione
public class Automobile {
    String marca;
    String modello;
    int anno;
    double velocita;

    Automobile() {
        this.marca = "Sconosciuta";
        this.modello = "Sconosciuto";
        this.anno = 0;
        this.velocita = 0;
    }

    Automobile(String marca, String modello) {
        this.marca = marca;
        this.modello = modello;
        this.anno = 0;
        this.velocita = 0;
    }

    Automobile(String marca, String modello, int anno) {
        this.marca = marca;
        this.modello = modello;
        this.anno = anno;
        this.velocita = 0;
    }

    void accelera(double incremento) {
        velocita = velocita + incremento;
    }

    void frena(double decremento) {
        velocita = velocita - decremento;
        if (velocita < 0) {          // una macchina non va in retromarcia frenando
            velocita = 0;
        }
    }

    void stampaInfo() {
        System.out.println(marca + " " + modello + " (" + anno + "), " + velocita + " km/h");
    }

    public static void main(String[] args) {
        Automobile[] auto = new Automobile[3];
        auto[0] = new Automobile("Fiat", "Panda", 2020);
        auto[1] = new Automobile("BMW", "Serie 1");
        auto[2] = new Automobile();

        auto[0].accelera(50);
        auto[0].accelera(70);
        auto[1].accelera(30);
        auto[1].frena(100);          // sarebbe -70: il metodo la riporta a 0

        for (Automobile a : auto) {
            a.stampaInfo();
        }
    }
}

Output:

Fiat Panda (2020), 120.0 km/h
BMW Serie 1 (0), 0.0 km/h
Sconosciuta Sconosciuto (0), 0.0 km/h
  • I tre costruttori hanno parametri diversi (0, 2 e 3): Java sceglie da solo in base agli argomenti di new.
  • this.marca = marca distingue l'attributo dal parametro; in accelera non serve this perché il parametro si chiama incremento, non velocita.
  • new Automobile[3] crea tre caselle vuote: le abbiamo riempite tutte e tre prima del ciclo, quindi niente NullPointerException.
  • Il controllo in frena (velocità mai negativa) è un'aggiunta nostra: le slide non lo chiedono, ma rende il modello più realistico.
